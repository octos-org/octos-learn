# 白板响指整理彩蛋

2026-11-06 在本机 `octos-learn-studio` 接入；2026-11-09 移到独立分支 `claude/snap-neat`（基于最新 main，适配新版隔空书写面板），待用户真机验收。入口为正常白板 <https://127.0.0.1:5173/board>，沿用本机 HTTPS 5173、Octos 50080 和既有账号。未发布公网。

## 使用

1. 在设置 → 实验功能开启“隔空书写”（此前已开启则无需重复）。
2. 白板工具栏开启“隔空书写”，在右侧控制面板点击“开启彩蛋”，允许麦克风访问。
3. 隔空写下公式，再用白板矩形框选工具选中这些笔迹。直接框选会暂停书写，彩蛋独立跟踪响指手型。
4. 等待提示“准备好了，打一个响指”，打响指。清晰识别的公式将以机器排版矢量笔迹替换原选区。
5. 点一次撤销可恢复原手写，重做可恢复排版版本。刷新后继续保留保存的结果。

声音门槛固定采用本次用户实测的 **0.079**，手型门槛 0.35、稳定 80 毫秒，手型与声音按 ±250 毫秒配对，声音使用“音量突增”模式，无 ASR。试验页默认门槛也改为 0.079。

## 行为与边界

- 开启彩蛋后才申请麦克风；有选区时才运行独立的手型跟踪。复用既有摄像头租约，不重新实现书写输入或选区。
- 没有选区、只看到手型、只收到声音、课程播放中、页面在后台或有对话框时，均不发起公式整理。
- 触发后只上传冻结的选中笔迹图片，用本人当前模型配置调用既有 `learning.teach.ink-to-math`。摄像头与麦克风数据仅用于本机手势检测。未修改模型提示词或课程生成路线。
- 识别结果须 readable 且 confidence=high，再由本地排版库生成矢量。识别不清、排版不完整或当前选区/笔迹已变化时保留原稿。选中内容含 AI 笔迹时不再次整理。
- 同一轮识别期间不并发请求；一次触发后须松开手势或重新选择才能再次触发，防止保持同一手型时背景声反复触发模型。
- 音量突增并不是专门的响指声分类，仍可能与其他短声混淆；本次没有宣称跨人群准确率。

## 实现

`src/learning/gesture/use-snap-neat.ts` 负责本机配对、资源生命周期和防重复；`snap-neat.ts` 冻结选区、复用识别、校验异步结果；`neat-math-paths.ts` 使用本地 MathJax SVG 和 svgpath，把公式转成能被既有 js-draw 接收的显式矢量路径。图形按原选区等比居中，不改写或求解公式。新增依赖按精确版本锁定。

既有 Ink Runtime 只支持追加 AI 路径或单独删除选区。替换能力已作为正式接口 `replaceSelectionWithAiPaths` 加入 OLL 墨迹运行时（octos-lesson-language PR #32），本仓库直接依赖该版本，不再使用本地补丁。它在同一同步提交前核对文档身份、内容修订、选区修订和笔画 ID；擦除原选区与插入 AI 路径进入同一条撤销命令。来源标记、消费身份及 SVG 继续使用原有保存机制。
