# 现成角色初筛：外观、动作来源与接入条件

日期：2026-11-03。用户已否定 DeepAR 的价格和外观，授权先筛选几套完整成品并展示外观与已有动画，再决定接入。手臂仍暂缓。

本轮交付是**角色视觉候选**。没有下载/安装角色或 SDK，没有采购、联系作者、启动相机或替换当前实验页。找到了作者发布的动作视频链接，但未播放验收视频，不能将其当成本项目的捕捉表现。

## 1. 虹色まお / Niziiro Mao：优先比较精细插画与嘴型

![官方角色图](https://www.live2d.com/wp-content/uploads/2026/06/sample-img-niziiromao.jpg)

- 类型：Live2D 官方完整样例，橙发魔法师风格。
- [角色与下载说明](https://www.live2d.com/en/learn/sample/niziiro-mao/)；[官方动作演示](https://www.youtube.com/watch?v=S8KzWsDIS1g)。视频地址取自官方角色页嵌入，不是他人的同名角色。
- [官方技术介绍](https://note.com/live2dnote/n/nb2c8302a7e25)解释了元音嘴型、眉毛和头发的形变，以及组合形变的限制设置。相比只有开合嘴，它值得用于验证口型和组合表情。
- 取舍：适合精细插画风；二维转头仍有角度边界，不能当完整三维侧脸。
- 成本/许可：样例免费提供验证；正式发行仍需要分别判断样例许可和 Cubism SDK 应用许可。不能称为永久免费商用方案。

## 2. 柚希くん / Yuzuki：优先比较完整三维少年角色

![作者角色图](https://booth.pximg.net/1f267d2d-50f4-463a-8427-4ba381d766d5/i/6689114/e1f60786-6648-43f9-a8ce-4383cec0217a_base_resized.jpg)

- 类型：作者制作的动漫少年，带猫耳，提供 VRM 与其他格式。
- [作者商品页](https://booth.pm/ja/items/6689114)；[作者附带的视频](https://www.youtube.com/watch?v=LUokVTeVE2U)；[作者嵌入的三维模型页](https://hub.vroid.com/characters/5096539580401204990/models/7064963767265435109)。
- 页面列出包含 Perfect Sync 的表情制作；完整包标注共 263 个形变项。不能据此推断 VRM 单独版本包含所有项目，需实际资产检查。
- 公开价格：VRM 单独版 1,600 日元；完整包 5,000 日元。本轮未购买。
- 取舍：有完整侧面几何，适合比较转头和耳朵/头发轮廓；Unity/VRChat 展示中的材质、灯光、动作不能直接视为网页 VRM 结果。
- **授权待确认**：页面指向 VN3 条款文件夹，并仅明确可在他人无法使用模型的情况下上传个人平台。没有确认网页向全体用户发送资产的权限，暂不能作为产品内置角色。个人购买价不等于产品分发授权价。

## 3. 小春／晴斗 / Koharu & Haruto：比较儿童风格与成对角色

![官方成对角色图](https://www.live2d.com/wp-content/uploads/2026/06/sample-img-SD.png)

- 类型：Live2D 官方女孩/男孩成对样例。
- [官方角色与下载页](https://www.live2d.com/en/learn/sample/koharu-haruto/)。
- 页面提供完整运行资产、物理设置和预制动作，也列出闪亮眼、流泪等表达。这些预制效果不等于相机能连续识别对应情绪。
- 取舍：更贴近低龄儿童风格，精细程度与成熟动漫形象不同。当前未找到并核实该组合的官方独立动作视频，不能给它配上其他同名角色视频。
- 成本/许可：样例免费验证，正式产品许可判断同上。没有将模型接入本项目。

## 当前建议

先让用户比较这三组真实外观。偏精细插画和嘴型表现：优先看 Mao；偏三维转头：看 Yuzuki 的完整角色方向；偏低龄化：看小春/晴斗。

这是外观与技术方向选择，并不等于采购或 SDK 集成决策。尤其 Yuzuki 的网页分发授权未确认，不能先购买后假设可以内置。

用户若更喜欢某组，可以先以可用样例验证同类效果；只有授权允许且模型能力满足要求，才接入现有 MediaPipe → 参数 → 渲染与课程回放。仍需按[路线重选方案](LEARNER_AVATAR_DOUYIN_REASSESSMENT.md)验证组合表情、匿名输出、最终配音、课程包和电视。
