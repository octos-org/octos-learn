## 实际技术

`摄像头视频 → MediaPipe Face Landmarker → 表情系数与头部姿态 → 校准/平滑 → Canvas 2D 局部变形 → 显示/参数录制`

- **素材准备**：一张完整立绘，另补眼口眉移动后露出的毛发底画及口腔内部。坐标、遮罩、眼皮和嘴唇曲线按角色手工拟合，尚非任意图片自动绑定。
- **捕捉**：`FaceCapture` 请求前置视频（理想 640×480、30 FPS，不请求麦克风），约 20 次/秒向 Worker 提交帧。产品 MediaPipe 模型和 WASM 在本机识别表情系数与姿态矩阵，不将视频上传给图像生成服务。
- **映射**：`eyeBlinkLeft` 驱动左眼皮、`jawOpen` 驱动张嘴、`mouthPucker` 驱动圆唇；矩阵转换为点头、左右转头和侧倾角。`FaceSmoother` 提供平滑、中性校准及失跟归位。
- **绘制**：固定原画眼球采样位置，移动眼皮形成遮挡；嘴唇分开后填入口腔；眉线局部移动。头部用 14×14 网格和逆向采样做有限形变，颈部权重减弱、衣服下部固定。最终是同一连续画面。
- **录制**：试验室记录随时间变化的表情和角度参数，回放时重新驱动绘制器，不是保存真人视频。

没有使用 Live2D Cubism 或三维重建。imagegen 仅用于制作素材，不参与每帧生成。当前不恢复原图没有的完整侧脸；尚无视线、手臂或全身跟随。
