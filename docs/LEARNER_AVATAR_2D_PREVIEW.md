# 二维星狐：首个可播放小样

日期：2026-11-02。用户要求“做一个效果给我看看”。本轮交付可运行的二维插画小样与可直接查看的动图，未将小样当作已完成的录课发布功能。

实现提交：`e9a79485`，独立分支 `codex/avatar-capture-prototype`。尚未推送、合并或部署。

## 可以查看的效果

本机正常应用：`https://127.0.0.1:5173/teach/avatar-2d`，需要既有登录；录课规划页“体验动态头像”也进入此处。既有 HTTPS 5173 和后端 50080 实例保留，不需要先合并 PR。

- “只看动作”：播放明确的合成演示，嘴部开合、眨眼、轻微点头/歪头和视线变化；不启动摄像头或声音。
- “听星狐讲一讲”：播放约 13.49 秒的固定中文分数讲解，嘴部读取该音频的真实 `currentTime`。支持音频控件的暂停/定位；嘴型仍是 RMS 音量包络，不是音素识别。
- “认真讲解”“想一想”“我发现了！”：改变眉毛、嘴角和头部角度，不生成新的课程内容，也不声称识别出孩子情绪。
- 旁边的分数卡是固定数学示例，明确标注场景示意；没有把它当作真实 OLL 板书或新录制作品。

聊天动图使用相同的绘制函数离线输出，105 帧、15 FPS、约 7 秒循环、无声。它是实际程序动画，输入为合成演示参数；不是摄像头捕捉证据，也不是浏览器录屏。导出依赖仅在 `/private/tmp/octos-2d-preview`，没有加入产品依赖。

## 实现与素材

- `illustrated-fox.ts`：无 DOM 的 Canvas 2D 绘制函数。插画底稿没有旧眼睛/眉毛/嘴巴，程序绘制独立眼球、虹膜、眼皮线、眉毛和连续嘴型，不在原有五官上覆盖补丁。主体与头部按颈部做小范围裁片变换，未做任意角度转身或完整 Live2D 网格绑定。
- `illustrated-avatar-stage.tsx`：本地图片加载、30 FPS 上限、像素比上限 1.5、按需重绘；暂停后停止持续帧，隐藏页停止渲染，超时与迟到结果处理，卸载释放图片回调/观察器/定时任务。
- `illustrated-avatar-page.tsx`：独立按需加载路由，只在点击后读取本地示例音频。准备阶段隐藏/暂停/退出均取消迟到任务，退出释放音频 URL。没有麦克风、相机、网络语音服务或付费模型调用；图片与 WAV 仍通过本机应用的静态资源请求加载。
- 静态资源位于 `public/teach-avatars/star-fox/illustrated-v0.1/`：`base.png` 为 1199×1312、带真实透明度的插画；`demo-lesson.wav` 为单声道 22050 Hz/16 bit PCM。
- 插画采用内置 image_gen 编辑流程，参照上一轮四种表现概念，重新制作无五官的动画底稿。没有使用 CLI 图像生成或项目 BYOK Key。[最终提示词](avatar-animation-phase-a/2d-concept/ANIMATION_ASSET_GENERATION.md)随项目保存。
- 示例声音使用本机已有 `Tingting (Chinese (China mainland))` 朗读原创文本，再以系统 `afconvert` 转成 WAV；不是录制真人、克隆儿童声音或产品最终音色。

实际示例文稿：

> 大家好，我是星狐。今天，我来讲二分之一加四分之一。先把二分之一，变成四分之二。再加上四分之一，就是四分之三。你也来试试看吧！

示例素材没有个人资料。未新增账号或服务凭据。

## 边界与后续

本轮仅新增二维预览入口，**未替换完整课程播放器/旧试验室中的三维舞台**，未修改草稿、课包或社区发布内容。旧三维实现作为历史工具保留。用户先看实际小样，再依据视觉反馈继续调整二维素材。

现有二维五官是代码绘制，仍可继续改进眼睛比例、线条/纹理融合、嘴型细节与脸部局部形变。自动眨眼/轻摆为明确的角色演出；静止时不持续摆动。当前没有精细中英文发音对齐、真实摄像头接入到此二维小样、举手/指板姿态、目标大屏帧率或儿童使用质量结论。

后续在小样风格得到实际反馈后，将此渲染器接入原有旁白时钟和表情参数回放，再推进角色资产版本随课包保存。详见[二维方向方案](LEARNER_AVATAR_2D_DIRECTION.md)。
