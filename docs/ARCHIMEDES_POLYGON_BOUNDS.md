# 圆与正多边形周长夹逼

`circle_polygon_bounds` 是与 `circle_and_arc` 并列的 Lesson Plan 能力，由 learning-coach 编译成 OLL `geometry`。沿用现有几何探索、大图、滑块、回放和存档流程。

OLL 新增 `regular_polygons`：中心点、固定圆半径、整数边数、内接或外切关系，以及可选旋转和周长说明。顶点和周长由程序计算，不由模型逐点生成。内接周长除以直径为 `n sin(π/n)`；外切为 `n tan(π/n)`。边数范围 3–384，教学计划统一为整数滑块。新内容要求播放器 0.4.0；既有课程的最低版本不变。

前端只更新固定的 OLL 依赖、对应版本清单和回归测试。通用后端、语音服务及 APK 打包不在本次改动范围。

验证包括 3–384 边的等边性、切线距离、周长与单调收敛；课程生成与校验；浏览器 6/12/24/48/96 边切换、固定圆、刷新、回放、旧缓存失效和说明布局。数学说明中的小数显示为近似值；严格不等式的十进制端点向外取整。
