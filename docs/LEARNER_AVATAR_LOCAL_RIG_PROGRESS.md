## 实际完成

1. **画面左耳独立材质**：从认可画稿提取原可见耳像素；用 imagegen 补完整耳根及后侧毛面。补画完整耳根只用于原本被头发遮住的部分。前/后毛面共用一条轮廓、同一支点与变换，有限侧转时改变内耳/外侧毛面的可见内容。
2. **耳前遮挡**：前发保留为独立遮挡层；耳朵从它后面转动。补画底板覆盖耳部移开后露出的纸面与头侧区域，不继续扭动相邻发丝。
3. **画面右侧一撮侧发**：保留原画纹理与透明轮廓，按两段骨骼驱动。发根固定、两段骨长保持；关节使用连续权重，限制在小角度范围，避免把整片头发拖动。
4. **中性重组**：通过原像素、补画底板与预乘透明图层重组；静止重建最大差异 1/255。脸部表情与衣服保留原绘制器；另一个 agent 改善的嘴线没有重做。
5. **头动驱动**：继续使用现有捕捉、平滑、耳向与发梢惯性控制器，将其输出映射到局部运动。新版跳过整图耳发的宽范围权重，保留头部基本跟随。此次只动一耳/一束，其余耳发仅随头部整体移动；不是完整头发绑定。

当前仍是局部二维近似：耳朵为带纹理的平面，有限投影缩短与耳背内容变化，不是真正三维耳廓、任意侧脸或完整压耳。发束关节也允许有限局部压缩，不保证每条毛纹长度严格不变。

## 本轮发现与修正

- 首次只提取可见耳部，侧转后显得脱节；随后补画完整耳根，把它藏在前发之后，向下调整支点。不能把第一版“中性重建几乎零差”的数值当作侧转合格。
- 最早的发束权重在两种投影切换处不连续，导致局部三角形翻折；改成连续横向过渡。
- 后续检查发现虽不翻折，局部面积指标最小只有约 28.3/88；扩大关节权重过渡后达到约 54.1/88，没有通过放宽 40 的下限规避。
- 原耳轮廓附近出现残线，扩大提取/移除区域并保留前发遮挡后修正。图片的外部纸面没有作为发束的一部分移动。
- 独立工作区复用已有依赖时，pnpm 默认检查试图重新安装并因无交互终端中止。使用 `--config.verify-deps-before-run=false` 后完成正常构建/启动，没有重装或删除另一个工作区的依赖。
