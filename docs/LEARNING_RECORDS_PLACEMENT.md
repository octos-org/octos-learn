# 学习记录放在哪里

日期：2026-10-28。分支 `codex/learning-records-placement`。

## 起因

第二阶段做的学习记录（`learning-history` 服务与“学习记录”侧栏）一直在、测试通过，但学院大厅改版（8e22582）后很难找到：顶部导航没有它；主页只有“最近白板”里的“全部学习记录”，只上课程、没有自由白板的学生看不到这个入口；只能从白板左上角的菜单打开。星图和成就读的是同一份记录，不是替代。

## 用户决定（2026-10-28）

学习记录作为底层数据继续支撑星图和成就，同时按用途放到学生会去找的地方，不再作为一个四个标签的侧栏，也不完全隐藏。

| 原来的标签 | 现在 | 理由 |
|---|---|---|
| 继续学习 | 大厅的“继续上次的学习”按钮写明最近一次的白板或课程（含课程），“全部学习记录”到 `/records` | 最常用的动作；原来大厅只给最近的自由白板。2026-10-28 大厅改版时去掉了大厅里的最近列表，避免与下方“最近白板”和课程卡重复 |
| 学习经过 | `/records` 的“学习经过”；星图上点亮的星辰有“查看这颗星的学习依据”，直接打开该知识点的依据；设置“老师记得的事”里也有入口 | 星图不能是黑箱；第二阶段承诺的核对与“删除这次学习记录”要有固定位置 |
| 学习地图 | 删除，内容都在星图和成就殿 | 与星图重复，两处数字容易让人怀疑哪个对 |
| 周报 | `/records` 的“周报”标签（2026-10-29 起；原为独立页面 `/report`），大厅有“学习周报”卡片（周报开关关掉时不显示） | 每周回顾适合放在大厅，由老师来讲 |

其他：
- “下一步可以做什么”从地图标签移到大厅底部（仍受原开关控制，周报下方照旧）。
- 颁发语“老师口吻/普通说法”的切换从地图标签移到设置 → 我的老师 → 高级选项。
- 白板里的菜单只保留切换白板和课程，另有“每次学习的经过与删除”，离开前照常先保存笔迹。
- 学生看到的“学习地图”字样改为“星图”；老师上下文里的【学习地图】段落不改，避免影响课程生成。

## 第二轮（2026-10-29，用户提出）

- **记录成为学院的第四处地方**：导航“大厅 · 星图 · 成就 · 记录”，手机底栏四格。`/records` 一页三个标签：学习记录、周报、月报。链接直接指到标签：`/records?tab=week`、`/records?tab=month`；`?tab=facts` 和 `?topic=` 打开“学习记录”里的“每次学习的经过”。旧地址 `/report` 跳到周报标签。周报和月报不再是同一面板里的切换按钮。标签支持方向键、Home、End，切换标签会进入浏览历史，返回键回到上一个标签。
- **周报下方不再有“下一步可以做什么”**：大厅已经有，避免重复。
- **“下一步”去掉“为什么推荐这个”，保留“不感兴趣”**。“不感兴趣”在服务端把这一条建议隐藏 14 天（按账号保存，各设备都生效）。用户曾反映刷新后“又出现”：查证后隐藏确实生效，出现的是同一知识点的另一条建议（同一知识点、不同的前置知识点）补上了位置，句子开头相同，看起来像同一条。解释后用户决定保留原机制不变（2026-10-29）。中途曾短暂删除该机制，开发机上的两条隐藏记录因此丢失，已从备份按原时间恢复；未发布，线上不受影响。
- **星图页去掉“按星域列出”**。代价：星图是画布，读屏和键盘用户原来靠这个列表看已点亮的知识点；现在只能通过“记录 → 每次学习的经过”看到每节课的知识点。

## 对上课速度的影响

课程生成不受影响：请求内容和模型调用次数都不变。大厅多读一次下一步建议（原来打开侧栏时才读），不调用模型。播放有改动：旧课回放时的立绘、旁白音色和课堂反应按原来的老师（见 [ACADEMY_HALL_AND_ACHIEVEMENTS_PLAN.md](ACADEMY_HALL_AND_ACHIEVEMENTS_PLAN.md)“课和老师的对应”），在别的设备上首次打开时旁白会等一次与课程加载并行的读取。
