# 学习记录放在哪里

日期：2026-10-28。分支 `codex/learning-records-placement`。

## 起因

第二阶段做的学习记录（`learning-history` 服务与“学习记录”侧栏）一直在、测试通过，但学院大厅改版（8e22582）后很难找到：顶部导航没有它；主页只有“最近白板”里的“全部学习记录”，只上课程、没有自由白板的学生看不到这个入口；只能从白板左上角的菜单打开。星图和成就读的是同一份记录，不是替代。

## 用户决定（2026-10-28）

学习记录作为底层数据继续支撑星图和成就，同时按用途放到学生会去找的地方，不再作为一个四个标签的侧栏，也不完全隐藏。

| 原来的标签 | 现在 | 理由 |
|---|---|---|
| 继续学习 | 大厅的“继续上次的学习”按钮写明最近一次的白板或课程（含课程），“全部学习记录”到 `/records` | 最常用的动作；原来大厅只给最近的自由白板。2026-10-28 大厅改版时去掉了大厅里的最近列表，避免与下方“最近白板”和课程卡重复 |
| 学习经过 | `/records` 的“学习经过”；星图上点亮的星辰有“查看这颗星的学习依据”，直接打开该知识点的依据；设置“老师记得的事”里也有入口 | 星图不能是黑箱；第二阶段承诺的核对与“删除这次学习记录”要有固定位置 |
| 学习地图 | 删除，内容都在星图和成就殿 | 与星图重复，两处数字容易让人怀疑哪个对 |
| 周报 | 独立页面 `/report`，大厅有“学习周报”卡片（周报开关关掉时不显示） | 每周回顾适合放在大厅，由老师来讲 |

其他：
- “下一步可以做什么”从地图标签移到大厅底部（仍受原开关控制，周报下方照旧）。
- 颁发语“老师口吻/普通说法”的切换从地图标签移到设置 → 我的老师 → 高级选项。
- 白板里的菜单只保留切换白板和课程，另有“每次学习的经过与删除”，离开前照常先保存笔迹。
- 学生看到的“学习地图”字样改为“星图”；老师上下文里的【学习地图】段落不改，避免影响课程生成。

## 对上课速度的影响

无。改动都在大厅、记录页、星图卡片和设置，不进入课程生成、播放或老师上下文。大厅多读一次下一步建议（原来打开侧栏时才读），不调用模型。
