## 1. 产品愿景与核心定位

### 1.1 背景与愿景
在真实的学校课堂中，一位老师往往需要面对几十名学生，受限于课堂时间和精力，很难做到兼顾每个孩子的理解节奏和性格偏好；而学生在课后遇到疑问时，往往难以获得及时、耐心的个性化答疑。

**Octos Learn 的核心定位是一位“懂教学、有性格、随时陪伴”的 AI 智能老师，作为真实课堂之外的重要补充。**

我们希望借助 AI 的全天候响应能力与教学理解力，让孩子在遇到任何学习瓶颈时，都能有一位极富耐心、教学实力过硬、且具有鲜明性格特征的专属老师陪伴在侧，引导孩子去思考、去探索、去掌握。

### 1.2 多维助力体系（核心学习闭环）
为了激发孩子的学习内生动力并保障实际掌握效果，Octos Learn 从以下四个维度立体构建学习体验：

1. **个性鲜明的虚拟 AI 老师**  
   拒绝冷冰冰的通用 AI 助手。产品打造了一整套性格立体的虚拟教师团队，每位老师都拥有独立的世界观背景、高水准立绘、专属音色与 Q 版头像。不同老师拥有不同的教学风格（如鼓励型、严谨逻辑型、启发引导型），让孩子可以选择自己最喜欢、最契合的老师一起学习。
2. **基于知识图谱的自由探索**  
   知识不是零散孤立的题目，而是相互联结的网络。产品提供完整的学科知识图谱，学生从任意一个兴趣点或卡壳的知识点出发，都可以清晰查看其前置依赖概念（“学这个之前需要先掌握什么”）以及后续拓展内容（“学完这个还能探索什么”），帮助学生构建系统化的认知框架。
3. **即时正向反馈与激励体系**  
   通过点亮知识星图节点、解锁专属成就勋章、获得个性化称号等机制，让每一次提问、每一次理解和每一次练习都产生可感知的成长印记，持续激发孩子的学习兴趣与成就感。
4. **以教促学的“费曼学习法”**  
   “听懂”和“真会”之间隔着一道巨大的鸿沟。Octos Learn 提供低门槛的录课工作台，鼓励孩子自己当小老师，将学到的知识用自己的话讲出来并录制成微课。在整理板书、梳理逻辑和向他人讲解的过程中，孩子能对知识点完成深度的二次组织与牢固掌握。

## 2. 核心课程体系

Octos Learn 的所有教学内容均围绕**白板动态图形互动、手写体板书演进与同步语音讲解**展开，主要由三类课程形态构成：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          Octos Learn 课程体系                                │
├──────────────────────────┬──────────────────────────┬───────────────────────┤
│    1. 实时自动生成课程    │    2. 精品预生成课程      │    3. 学生录制课程    │
│  - 针对学生即时提问与难点 │  - 依托知识图谱体系化构建 │  - 践行“费曼学习法”   │
│  - 实时意图理解与 DSL 编译 │  - 人工教研深度校验与审核 │  - 录课工作台 + 2D动捕 │
│  - 丰富的底层互动组件支持 │  - 结构与自动生成课同构   │  - 课包沉淀与社区分享 │
└──────────────────────────┴──────────────────────────┴───────────────────────┘
```

1. **自动生成课程**  
   * **生成机制**：学生在白板上通过手写、拍照、语音或文字提出任何数理问题，AI 老师即时理解意图，动态规划教案并实时生成微课。
   * **交互式底层组件**：底层依托自研 OLL 引擎提供丰富的数学/科学交互组件（动态函数图像、参数滑块、几何体割补、坐标轴缩放等）。目前以中小学数学为核心，后续逐步扩展到物理、化学等多学科。
2. **知识图谱预生成课程（精品课）**  
   * **体系化沉淀**：依托学科知识图谱构建的标准化课程库，覆盖各年级核心知识点。
   * **人工教研严选**：经过人工教研团队的严格审核、脚本润色与图形调优，保障讲解的权威性与严密性。
   * **同构底层架构**：预生成课程与自动生成课程在底层数据结构、播放器协议和交互组件上完全一致，具备相同的动态交互能力。
3. **学生录制课程（小老师微课）**  
   * **创作与巩固**：学生在 Studio 录课工作台中自主备课，利用白板工具、公式整理和 AI 助教协助，边画边讲录制属于自己的微课。
   * **虚拟化表达**：支持选用 2D 卡通形象（星狐、小熊猫等），通过摄像头捕捉表情动作，搭配合成音色进行生动演绎。
   * **社区共享愿景**：录制的课包除保存在“我的课”中自查巩固外，未来将支持一键发布到学生学习社区，让同伴之间互相观摩、点赞与交流答疑。

## 3. 详细功能需求

### 3.1 虚拟 AI 老师与个性化教学
* **老师人物塑造**：每位虚拟老师具备完备的角色档案（立绘形象、性格设定、专属台词、Q 版半身像与头像）。
* **专属教学风格与音色**：
  * 不同老师在讲解时采用符合人设的表达风格（如更温和包容、或更有极客探究精神）。
  * 老师旁白配备辨识度高的专属音色，在授课与反馈时保持连贯的听觉体验。
* **随时随地切换**：学生可以在大厅或白板中按喜好选择当前的主讲老师，切换后后续生成的课程与点评均同步对应老师的形象与语音风格。

### 3.2 知识图谱与星图系统
* **双向知识拓扑网络**：
  * **前置依赖（Prerequisites）**：点击任意知识点，系统能清晰展开其前置概念链路，指出当前知识点建立在哪些基础之上，便于查漏补缺。
  * **后续延展（Next Steps）**：展示当前知识点后续可以推导出的高阶概念与跨分支应用，激发进阶探索欲。
* **可视化的星图点亮机制**：
  * 听完一节课：对应节点外环点亮“已探索”状态。
  * 完成随堂练习：节点进一步升级为“已练习”或高亮成就状态。
  * 录制讲解完该知识点：节点外围点亮独特的“小讲师（已讲过）”外环。

### 3.3 交互白板与确定性课程运行时 (OLL Runtime)
* **动态图象与互动控件**：
  * **函数与坐标系**：支持直角坐标系的动态缩放，支持线性函数、二次函数、幂函数、三角函数等实时平滑绘制。
  * **交互式滑块（Sliders）**：支持在白板中嵌入可拖动的数值滑块，学生或老师在拖动滑块时，图象与几何关系实时平滑重算（如观察二次函数顶点随参数移动）。
  * **几何图元**：支持绘制点、线、多边形、单位圆，以及长方体三维透视投影。
* **板书与语音严格同步**：手写笔迹随讲解语音的推进按笔画动态展现，杜绝传统的死板全屏翻页。
* **分步步进与暂停交互**：课程按逻辑卡片分段播放，学生随时可以暂停播放，在白板上亲自拖动滑块、测量图形，验证想法后再继续收听。

### 3.4 录课工作台 (Teach Studio `/teach`)
学生实践“费曼学习法”的创作中心，分为备课、录制、质检与打包全流程：

1. **教案规划（Teach Plan）**：
   * 学生输入想讲的主题与学习目标。
   * 自动生成卡片式结构（默认 4 张卡片：引入、推导、例题、练习），支持增删和排序。
2. **多模态录制工具坞**：
   * **自由笔迹**：铅笔、荧光笔、橡皮、带残影激光笔。
   * **手写转公式**：框选潦草的演算手迹，一键智能转换为标准 LaTeX 印刷体公式。
   * **快捷插入实体**：一键在白板插入坐标系、函数图象、单位圆、长方体或过两点直线。
   * **规整分区排版**：支持“放在旁边…”智能排版，插入的卡片与组件自动归位，避免重叠杂乱。
3. **分卡片录制与精准容错**：
   * 逐张卡片录制，录制中实时将学生语音转写为屏幕字幕。
   * 录制完成后支持人工校对编辑字幕。
   * **重录我的话**：保留白板上的所有板书和图表动作，仅清除并重新录制语音讲解与激光手势，大幅降低录课心理负担。
   * **整张从头录 / 撤销**：随时撤销单步操作或完全清空单张卡片从头开始。
4. **AI 助教协同质检（“检查我的课”）**：
   * **可读性检测**：自动核验不同分辨率屏幕下每张卡片的最终文字大小（≥ 12.5 px），检查是否有图表遮挡或出界。
   * **小章鱼助教点评**：分析讲解逻辑与板书，给出鼓励性建议与优化提示。
   * **基础隐私提醒**：扫描字幕与板书，提示避免出现学生本人的真实姓名、电话或住址等个人敏感信息。

### 3.5 2D 虚拟形象与摄像头动捕驱动
* **角色立绘阵容**：提供 4 款手绘风格的高品质 2D 卡通角色立绘：**星狐 (Star Fox)、小熊猫 (Red Panda)、白兔 (White Rabbit)、月猫 (Moon Cat)**。
* **端侧摄像头表情与头动捕捉**：
  * 学生在录课时可勾选“用摄像头带动我的形象”。
  * 端侧利用视觉模型提取人脸姿态与表情参数（包括张嘴、微笑、眨眼、头部俯仰转动、耳廓转向与发梢随动）。
  * 仅提取参数，不上传任何摄像头真实画面。
* **合成音色与动作多轨对齐**：
  * 学生选择自己喜欢的虚拟老师音色作为配音。
  * 系统在打包课件时，自动将录制时的头动与表情动作对齐到最终的配音时间轴上，播放时结合语音唇形算法（Lip-sync）合成生动的虚拟人主讲动画。

### 3.6 激励反馈与成长报告
* **成就体系**：设立覆盖“自学探索”、“动手互动”、“录课当老师”等多维度的成就勋章（如“小讲台”勋章、连续学习称号等）。
* **成长周期总结**：基于学生真实的听课、练习与录课记录生成周报与月报，客观记录知识掌握与实践轨迹，鼓励持续进步。

### 3.7 课包管理、离线播放与社区愿景
* **独立课程包格式（`.olesson`）**：将讲解步骤、板书轨迹、数学组件状态、配音与虚拟人动作封装为独立课包文件，支持在本地下载与分发。
* **“我的课”管理中心（`/teach/lessons`）**：查看全部已录制微课与编辑中草稿，支持本地与账号双向同步。
* **离线互动播放器**：
  * 无需联网与 API Key，随时随地离线观看。
  * 播放中数学组件保持完全可交互，课末自动挂载配套的随堂互动练习（“轮到你了”）。
* **社区生态规划**：后续版本将推出“学生微课社区”，孩子录制的作品可一键分享至班级或公开广场，其他同学可以观看微课、动手做练习并为小老师送上点赞与评价。

## 4. 基础运行与体验保障

### 4.1 终端与设备兼容
* **Web 端**：兼容主流桌面浏览器（Chrome、Edge、Safari 等），支持键鼠交互与数位板/触控屏输入。
* **Android 触控大屏与平板**：
  * 提供独立 APK 安装包，兼容 Android 8.0 及以上系统。
  * 深度适配会议机与教室智慧黑板（如皓丽等大屏触控设备），支持全屏沉浸式教学。
  * 专门优化大屏触控的防手掌误触（Palm Rejection）与多指平移手势。

### 4.2 性能体验要求
* **白板书写流畅度**：手写延迟控制在 30ms 以内，支持高刷触控采样，书写平滑无锯齿。
* **生成响应体验**：自动生成课程时首个片段的生成与渲染保持即时流畅，避免长时间白屏等待。
* **动捕计算开销**：端侧面部动作捕捉算法在普通设备上保持平稳运行，不引起画板掉帧或音频卡顿。

### 4.3 基础安全与易用性
* **大屏演示模式**：提供课堂演示快捷开关，在公用大屏幕上一键隐匿个人历史、草稿与私人笔记，专心用于教学展示。
* **成本保障与灵活性**：
  * 支持 BYOK（自带主流模型 Key），满足高频深度自学需求。
  * 平台提供适量配额的托管语音合成服务，保障普通用户开箱即用的优质听觉体验。

## 5. 演进路线图 (Roadmap)

1. **第一阶段（当前核心版本）**：
   * 完善个性化虚拟老师与白板数学互动组件。
   * 落地完整的知识图谱探索与星图点亮闭环。
   * 完成学生录课工作台（Studio）、2D 虚拟形象动捕驱动与 `.olesson` 离线课包播放。
2. **第二阶段（社区与互动深化）**：
   * 上线“学生微课社区”，支持作品发布、同伴互动、课后作业挑战。
   * 增加更多学科内容支持（如物理力学/电学模拟、化学反应方程式）。
3. **第三阶段（高级生态）**：
   * 引入更多风格的虚拟教师与角色定制系统（支持 Live2D / 3D VRM 形象导入）。
   * 支持远距离隔空手势（Air-Writing）板书，满足智慧教室无接触大屏教学场景。
