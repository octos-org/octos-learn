# 公开注册、新手设置与平台旁白语音

## 用户第一次进入

分享 `https://learn.pitun.cc` 即可。新邮箱通过验证码验证后自动注册为普通用户，不获得管理员权限，也不会取得管理员的模型或语音密钥。

没有配置模型的新用户进入 `/setup` 设置白板。在卡片内填写、测试并保存自己的模型凭据；语音和摄像头均为可选。已有模型配置的用户直接回到原来的白板。选择「稍后设置」只在当前浏览器、当前账户记录一个跳过标志；不保存密钥。

公网版本的课程生成服务目前固定使用 Gemini。设置卡片优先提供 Gemini API Key，不将「其他聊天平台测试成功」误当作「课程生成已就绪」。本地开发的完整设置仍保留其他模型平台。

设置卡片是普通受认证表单，不是 OLL 课程块。密钥不会进入白板快照、导出、手写数据、课程内容或模型上下文。以后从 **Settings → 新手设置白板** 重新打开。高级模型、个人 TTS 和老师形象设置仍保留。

`learning-coach` 是 Octos Learn 的内置运行能力，由服务端通过 `OCTOS_SKILLS_PATH=/opt/octos-learn/skills` 提供给所有账户。用户不需要安装、升级或管理它；Octos Learn 的 Settings 不显示通用 Skills 页面。未来的学科能力包属于学习产品内容，不通过面向用户的 Skill 安装入口分发。

## 不同功能各自降级

| 缺少的服务 | 仍可使用 | 暂不可用 |
|---|---|---|
| LLM | 手写白板、已有课程 | 新课程、AI 局部辅助 |
| TTS 或共享额度用完 | 课程生成、文字旁白、手写与互动 | 旁白声音 |
| ASR 忙碌或离线 | 打字、上传图片、课程播放 | 语音提问 |
| 摄像头或未授权 | 打字、手写、语音（若可用） | 实时拍照 |

ASR 当前只有一个识别会话。占用时提示「语音服务正在使用中，你可以继续打字」，不会为等待 ASR 而禁止文字输入。默认不申请麦克风或摄像头权限，用户进入白板后主动启用。

## 平台 TTS 的默认额度

| 项目 | 初始值 |
|---|---:|
| 平台每月合成字符上限 | 100,000 |
| 每用户每月合成字符上限 | 10,000 |
| 计量周期 | UTC 自然月，每月 1 日 00:00 重置 |
| 全平台合成请求上限 | 60 次/分钟 |
| 平台同时合成上限 | 2 个请求，最多等候 3 秒 |
| 每档案的既有限流 | 20 次或 20,000 字符/分钟；同时 1 个请求 |

火山官方产品页列出的语音合成参考价为 **5 元/万字符**。据此，10 万字符约 50 元；音色、套餐、优惠和供应商计量方式可能不同，因此这是初期预算参考，不是账单承诺。

- [火山语音计费说明](https://docs.volcengine.com/docs/6561/1359370?lang=zh)（动态文档，自动抓取未返回价目表正文）
- [火山官方产品价格参考](https://www.volcengine.com/product/ark)
- [语音合成资源包](https://www.volcengine.com/product/TTS)

这里限制的是本站实际放行的请求字符数（含标点、空格，并为程序可能补上的末尾标点预留 1 个字符）。在向供应商发送前，SQLite 事务先记录额度；并发请求不能同时抢到同一份余额。请求失败、浏览器中断或超时不能证明供应商没有计费，因此不自动返还。刷新、重播和后续新合成会继续计量；已在浏览器中复用的音频不会重新调用供应商。

用量不是火山账单同步值。最终账单仍应查看火山控制台。不自动购买资源包，也不自动提高额度。

## 如何配置和修改

1. 管理员在自己的 **Settings → Voice** 中配置火山 TTS 并成功试听。
2. 在服务端 systemd 环境文件中设置 `OCTOS_SHARED_TTS_PROFILE=admin`（实际管理员档案 ID 以服务器为准），然后重启 Octos。这不是密钥，只指定共享语音的来源。
3. 管理员打开 **Settings → Voice → 平台提供的旁白语音 → 管理员额度设置**，启用并保存上表额度。上线前默认关闭，避免仅设置来源就产生无上限费用。
4. 同一位置可以修改平台和个人月限额，立即生效，不需要重新编译或重启。设为 0 或取消启用即可停止平台代付。
5. 普通用户在同一页只看到自己的用量、上限及平台是否可用；不能改变限额或读取其他用户用量。管理员额外看到平台总用量。

用户已配置个人云端 TTS 时继续使用个人凭据；明确选择本地 TTS 也不会消耗平台额度。没有个人 TTS 覆盖的用户才采用平台默认。平台密钥不复制进新用户档案，也不注入全局 `VOLC_TTS_TOKEN`，因此其他技能、网关或旧语音接口不能绕过本接口的额度使用这份平台密钥。共享语音目前服务于 Learn 调用的 `/api/voice/synthesize` 接口。

管理员自己的 TTS 配置仍是个人配置，不会计入这份共享池。需要测试共享池时应使用普通测试用户，避免把管理员试听误当作共享计量验证。

## 部署、迁移与回退

- 后端和前端必须一起部署；旧后端没有 `/api/voice/shared-tts`，新前端会提示无法查询用量，不应当成已启用共享语音。
- 持久用量及额度保存在 Octos 数据目录的 `shared-tts.sqlite`（此 VPS 为 `/var/lib/octos-learn/octos/shared-tts.sqlite`）。迁移时连同用户、管理员 TTS 配置及凭据存储一起备份；停服复制数据库，避免遗漏事务。
- 不要删除数据库来重置额度。月度重置按新月份自然生效，历史用量保留。
- 本地开发不设置 `OCTOS_SHARED_TTS_PROFILE` 时不启用共享池，继续使用原来的个人/本机语音配置。无需 SMTP、VPS 或 Agora 才能开发文字白板。
- 回退版本时先关闭平台 TTS、将注册改回邀请制，然后恢复上一份前后端构建；保留数据库和用户数据，不删除新用户档案。

### 人工验收清单

1. 新邮箱注册：得到普通账户，进入设置白板，无法访问管理接口；已有管理员直接进入原白板。
2. 不填模型选择稍后设置：可以手写，AI 操作提示连接模型；回到设置白板配置 Gemini 后可生成课程。
3. 不填 TTS：普通用户试听平台语音，用量增加且页面不返回管理员凭据；管理员能看到总量。
4. 临时把限额设到已用量：新合成被阻止，但文字旁白和课程继续；恢复额度后可再次试听。
5. 两个用户同时启用语音：第二个得到忙碌提示，仍可发送文字。关闭首个语音会话后第二个可以重新启用。
6. 用户填写自己的 TTS：试听和课程旁白正常，共享池用量不再增加。
7. 刷新/重启服务：已用额度不清零；摄像头图片和既有课程回放不受影响。
