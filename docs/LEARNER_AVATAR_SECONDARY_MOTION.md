# 四角色：可见耳发随动与静止小动作

> 用户随后否定本轮耳动自然度，现已按[动物资料](LEARNER_AVATAR_ANIMAL_EAR_RESEARCH.md)重做为[耳廓主动转向/保持/回正](LEARNER_AVATAR_EAR_ORIENTATION.md)。本页的耳部弹簧/正弦动作及媒体属于旧版本；仅发梢仍使用减弱的阻尼随动。

日期：2026-11-03。用户指出四款耳发随动仍难以察觉，并要求静止时偶尔出现类似动物的耳朵、头发/毛发轻动。本轮保留四款原画，修改局部变形与动画调度，不调用图像生成服务。

## 页面使用与实际结果

仍在 `https://127.0.0.1:5173/teach/avatar-2d`，刷新加载。**“耳朵与毛发自然小动作”默认开启**，没有摄像头也能观察；开摄像头后同样有效。四款角色使用不同耳根、耳尖、随动幅度与时间相位。

- 摆头：整个头部跟随之外，耳朵和发梢产生更明显的局部滞后，停下后回落。测试组合中，耳尖相对刚性头部的额外位移约 20–30px（704px 原生纹理坐标），不再是上版数像素的小变化。
- 静止：左右耳分别间隔轻拨/回弹，不会一直同步摆动。耳朵触发周期分别为 7.7s 和 10.3s，每次约 1.35s/1.65s；发梢有低幅缓动和间歇轻摆，各角色相位错开。
- 定格检查及动作轨回放模式暂不添加自然小动作，暂停后保持定格；回放中仍有头动驱动的随动。
- 取消勾选会停止自动耳发动作；摄像头/演示中的真实头动仍驱动随动。页面隐藏/卸载时停止绘制。
- 手动/演示/摄像头录制保存的仍是原表情参数。自然小动作属于装饰动画，**没有写入动作轨**；尚未扩展正式课程包。不要宣称录制视频、课程导出已经包含这些装饰动画。

## 上版为什么看不出来

上版局部附加角度只有约 0.02–0.04 弧度，发梢平移 2.5px；缩到预览尺寸后非常弱。角色使用共同的狐狸耳部位置，白兔长耳和小熊猫圆耳不合适。`AvatarLabPage` 没有传入 `idleMotion`，并且舞台在 `active=false` 时停止调度；仅增加时间函数不会让静止页面真正动起来。

## 本轮代码

- `painted-secondary-motion.ts`：独立局部变形模块，耳朵绕各自根部轻转、发梢/额发局部移动；耳尖位移和角度受限。左右耳和头发使用阻尼弹簧，随头部目标变化后滞后/回落。自然动作是确定的时间函数，帧间不抽随机数。
- `painted-characters.ts`：四款各自的耳根/耳尖、影响宽度、幅度与相位；白兔长耳降低角度增益，小熊猫短圆耳稍加强。
- `painted-fox.ts`：先局部随动，再施加原刚性头部变换；在“头部角度为零但耳发仍动”时同样执行变形。修复这一情况下跳过不动三角形导致清空脸部的隐患：静止三角形仍负责恢复画面。
- `illustrated-avatar-stage.tsx`：`idleMotion` 自身足以维持动画帧，不再依赖摄像头/演示 `active`。帧率仍受现有 30/60 限制，隐藏时停止。
- `avatar-lab-page.tsx`：默认开启开关；`mode==='replay'` 时停用装饰动作。手动控制和相机不因开关而重启。

脸部表情通道、嘴部纹理、原画与选角目录均保留。没有增加模型或产品依赖，没有做侧脸重建或手臂动画。

## 时间与回放边界

弹簧积分步长最大 1/120s，阻尼系数 0.62；耳朵/头发角频率分别为 17/12。使用输入 `FaceFrame.timeMs` 更新：重复时间戳冻结，倒退或超过 250ms 的间断重置到当前姿态，避免切换/跳转时带入上一段弹力。未传绘制时间的离线定格输出使用平衡姿态，便于像素复现。

自然动作使用绘制时间加角色相位，同一时间可重现。弹簧历史没有序列化，回放跳转会重置；连续播放/不同绘制采样率的物理细节不保证逐像素一致。需要精确导出时，应在统一时间步长重新计算，或把二级动作烘焙到独立轨道，尚未实现。
