# 三课布局与开场修复交付记录

日期：2026-09-24。三节微积分课程版本：0.2.1。

## 解决的问题与具体实现

1. **比较图错位、公式四处散落。** OLL 新增 `packages/web-runtime/src/teaching-layout.ts`，由 `layout.ts` 的 `flow: teaching` 分支调用。根据显式图形关系、分组和控件的实际关联对象组成布局单元；单元内图形顶端对齐，宽度不够时换行。避障移动整个单元，不再逐张卡片往下挤。叙述卡片按创建事件所属教学步骤组织，在固定宽度内换行，取消旧阅读布局的“四项后另起远处一列”行为。
2. **滑块远离图形。** 宿主将控件和练习拆成两种布局附件。控件位于关联图形组下方 24 个白板坐标单位，并水平居中；练习单独放在后面的练习区。打开练习不会再将控件预留区撑高。
3. **偏导数课开场只有声音。** 本课首个公式是导入内容，审核后显式提前为 `before_speech`。其他动作和全部旁白保持原样。
4. **新生成课程的通用兜底。** OLL 新增 `applyLessonOpeningPolicy`；learning-coach 在 `explicit-v1` 构造模式下启用标题兜底。首段没有旁白前/旁白中显示的写入内容时，插入课程标题卡，不提前公开原本延后显示的答案或动画。只有调用方明确指定的导入别名才允许提前。默认旧策略保留原数据，引用已有白板的续讲不插入标题。
5. **宽度、字体与笔迹。** 宿主根据视口宽度更新区域宽度；节点真实尺寸变化继续使用已有重排机制。空白区域笔迹作为障碍物，卡片上的笔迹不拿来推动自己的卡片。笔迹边界没有变化时不重新分类，避免选中笔迹引起布局反馈。

## 数据与语音变更

三课从已审核的 0.2.0 数据重新物化、打包为 0.2.1。本轮不是重新用模型生成三门交付课程：第一、三课保留 authoring 内容，第二课仅提前导入公式的显示时机。每课的 `construction-review.json` 记录了策略。

37 段旁白文字不变，37 个音频文件与旧版逐字节一致。正确的曲面封面继续保留。旧 0.2.0 文件备份于 `/tmp/teaching-layout-backup-0.2.0`；发布目录也保留旧版本。原始模型候选没有覆盖。

另运行了一次真实生成验证，产物在课程库 `authoring/surface-partial-derivative-slice/candidates/candidate-007/`：4 次模型调用、27.553 秒、没有拒绝重试，首段自然生成可见图形，并通过共享 materializer。该候选仅用于回归，未替换已审核课程。它没有触发标题兜底；兜底、延迟答案不提前和旧模式保持不变由确定性测试覆盖。

这一次生成仍报告“连续域未证明”和“共同聚焦图形未声明布局关联”的警告，不能将它解释为数学语义或所有生成结果均已正确。程序不凭旁白猜测遗漏的图形关系。
