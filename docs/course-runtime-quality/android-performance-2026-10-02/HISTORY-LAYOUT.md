# 预制课历史恢复布局修复（2026-10-03）

## 现象与根因范围

用户反馈余弦预制课在旧学习记录中出现单位圆与余弦图错位；清除该记录后重新进入，位置恢复正确。原始会话包含一项笔迹和追加课程。旧记录删除后不能逐项重新验收原始会话，但保留的诊断布局与新隔离回归支持下面的恢复时序问题。

笔迹恢复订阅把当时已挂载的节点写入 `inkPinnedLayout`。课程后续节点到达时，OLL 的布局把未固定节点放到固定前缀下方，导致原本同行的比较图被拆开。该逻辑已存在于本轮性能优化前的 `d100e158ff62d10b28d706f74090b95d21deb758`。这是恢复链路的问题，不是已经确认的课件内容变更或记录格式损坏。

## 修复

`LearningWhiteboard` 增加 `preservePackagedCourseLayout`。CoursePack 宿主启用它；声明便携课程区域的调用也默认启用。原始预制课不使用笔迹的临时节点固定和避障矩形；普通白板与追加提问课程继续保留现有笔迹避障。修复没有清空、改写、迁移学习记录或笔迹文档。

保证针对同一课程版本与视口，在历史笔迹恢复前后原始课程布局一致；视口变化、练习展开等内容变化的独立适配行为不在这个回归断言中。

## 回归证据

`tests/android-course-restore.spec.ts` 在隔离浏览器里打开真实余弦课程，通过原生桥写入并保存一笔，随后同一 IndexedDB 上重新加载。笔迹先恢复、课程只显示首个图形，然后补全其他节点。比较全部节点世界坐标，并确认笔迹组件仍为一项。

- 修复前：回归失败，后续节点向下移动。
- 修复后：该回归和既有镜头、课程笔迹、图形预览、页面冒烟共七项无重试通过。
