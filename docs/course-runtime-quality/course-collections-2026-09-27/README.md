# 课程集与课程卡片 UI（2026-09-27）

## 信息结构

首页展示课程集，进入课程集后显示简介和按教学顺序排列的课程。`?collection=<id>` 保存当前集合，支持刷新、浏览器返回及直接链接。集内页面提供“全部课程集”返回入口。

课程集内容在 `src/learning/course-collections.ts` 独立维护，包括名称、学段、简介、专属 SVG 封面和有序课程 ID。成员关系不绑定版本，实际列表仍使用目录中可用的最新版本。未配置的新课程归入“其他课程”；空集合不展示。以后目录提供集合元数据时，可替换此配置，不必改卡片组件。

- 读懂一次函数：斜率 → 截距 → 方程交点。
- 从单位圆理解三角函数：正弦 → 余弦 → 单调性与象限。
- 用截面理解多元函数：等高线 → 偏导数 → 鞍点。

## 单课卡片

封面保持完整比例，不再叠放标签。详情首行展示学段/学科标签和次要版本信息；下方为课序、标题和简介。始终显示时长，下载状态独立显示。底部仅保留预览与开始/继续学习；重新开始和删除学习记录收进更多操作，保留原确认与记录处理语义，支持 Escape 关闭。

## 验证

17 项课程入口单元测试通过，包括集合导航、顺序、离线课程、版本选择、实例恢复和菜单操作。生产构建、针对修改文件的 ESLint 通过。临时静态生产预览使用真实九课目录及本地原始封面（认证状态响应隔离），在 1440、700、390 像素验证了导航、刷新、返回、继续学习菜单与横向溢出。临时服务及浏览器已关闭。教学播放代码未改动；原课程播放 E2E 的入口已适配集合路径，本次未重新执行完整语音播放测试。
