## trig-quadrants-and-monotonicity

### section-03/moment-02

随着角度从二分之三派增大到二派，动点的纵坐标从负一逐渐回升到零。因此，在这段角度范围内，角度越大，正弦值越大，正弦函数是单调递增的。

## surface-partial-derivative-slice

### section-03/moment-01

我们对截线函数求导。截线的高度等于 x 的平方加一，所以它的导数等于二乘以 x。在 x 等于一的位置，导数值就是二。

### section-03/moment-02

切点的横坐标是一，高度是二，切线斜率也是二。根据点斜式，高度 z 减二，等于二乘以 x 减一，整理得到 z 等于二乘以 x。这里的斜率二，表示高度增量与 x 增量的极限比值，不是用量角器在屏幕上量出的角度。

### section-03/moment-03

推广到一般位置，函数 x 的平方加 y 的平方，对 x 的偏导数等于二乘以 x。因此，在指定点处，偏导数等于该点 x 坐标的两倍。这里的结果与 y 坐标无关，是因为固定 y 时，y 的平方是常数，对 x 求导为零。这并不适用于所有曲面。例如函数 x 乘以 y，对 x 的偏导数等于 y，就依赖于 y 的取值。

## surface-saddle-point-analysis

### section-02/moment-01

对于马鞍面，高度 z 等于 x 的平方减去 y 的平方。我们分别沿 x 轴和 y 轴方向取截面，观察截面上的一元函数。

### section-02/moment-02

在 y 等于零的截面上，高度 z 等于 x 的平方。用路径参数 t 表示 x，高度就是 t 的平方。因此，在沿 x 轴的这条路径上，原点是最低点。

### section-02/moment-03

在 x 等于零的截面上，高度 z 等于负的 y 平方。用路径参数 t 表示 y，高度就是负的 t 平方。因此，在沿 y 轴的这条路径上，原点反而是最高点。

### section-02/moment-04

现在把两条截面曲线放到同一坐标系中比较。横轴是路径参数 t，纵轴是高度 z。开口向上的抛物线，对应 x 等于 t、y 等于零的路径；开口向下的抛物线，对应 x 等于零、y 等于 t 的路径。
