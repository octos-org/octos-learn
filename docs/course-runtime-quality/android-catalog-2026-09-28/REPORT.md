# Android 课程目录与真机更新（2026-09-28）

## 基线与根因

本次从远端 main `f006919fb6fd156e95d6fa89699151fcd7afa99d` 建立修复分支，包含 #33 与 #35。旧真机 APK versionCode 28 没有构建提交标记，无法准确追溯 SHA；提取资源确认已有 IndexedDB 代码但仍有“查看整课”，不包含当前完整主线。旧内嵌快照为 embedded-2026-09-18，含已撤下的长方形课及一次函数课。

## 修复

- Android 横屏视口宽度至少 800px 时课程集及单课列表采用三列；封面按视口高度约束，缩小卡片内留白，保留完整文字及至少 44px 的操作按钮。没有修改系统密度或白板坐标。
- 内嵌清单精确更新为公网推荐三集九课，构建逐包校验大小、SHA-256、身份及离线旁白。清单版本为 embedded-2026-09-28。
- 公网目录请求成功时，不再把已撤下的旧内嵌课程重新添加到推荐目录。离线内嵌入口及已有学习记录保留，不删除用户数据库。
- versionCode 升至 29；APK 增加 build-info.json，记录源码提交、工作区是否有修改、构建时间及内嵌清单哈希。
