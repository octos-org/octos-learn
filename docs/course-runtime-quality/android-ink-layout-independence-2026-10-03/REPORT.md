# 笔迹与课程布局解耦（2026-10-03）

## 行为

此前只要任意非空笔迹边界发生变化，就会测量并固定所有已显示课程卡片；空白区域笔迹还会成为后续课程布局的障碍。写在远处的一笔也会影响课程。CoursePack 原课程虽已有单独绕过逻辑，实时课程和后续问题课程仍受影响。

本轮统一删除笔迹触发的布局固定、课程及辅助卡片的笔迹避障，不再区分预制课和实时课程。问题卡片本身、其他课程区域仍参与避障；用户主动框选提问时仍以选中内容的位置作为问题区域的来源锚点。课程布局继续按课程内容、可用视口和正常播放流程计算，笔迹不再改变这些计算。既有笔迹保留世界坐标，课程因正常内容变化重排时，不会跟随卡片移动。

保留现有笔迹覆盖课程卡片的显示层次。保留“播放且浏览时隐藏笔迹”的规则，并在每次开始/继续播放时自动切回浏览工具，包含此前使用书写、擦除、框选工具的情况。暂停后笔迹重新显示且内容不变。播放中用户主动再选书写工具仍遵循原有显示行为；本轮不禁用工具。
