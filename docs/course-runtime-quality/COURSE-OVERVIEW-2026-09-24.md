# 整课布局与结束取景修复

## 范围与数据

本轮针对三节微积分课程暴露的纵向过长、结束练习裁切和缩放过小问题，修改共享 OLL 展示逻辑及应用宿主。三课继续使用 **0.2.1**，authoring 和 canonical 文件与本轮开始前逐字节一致；没有重生成课程、改旁白、改 prompt 或调用模型。音频和封面保持原样。

本记录取代上一轮交付文档中“长白板在结束时仍需平移浏览”的验收约定：自动结束状态现在要求全部已显示的本课卡片进入安全可视区域。用户之后手动导航仍保持自主控制。

## 已实现的机制

### 内容块与候选布局

OLL `packages/web-runtime/src/teaching-layout.ts` 增加视口驱动的排列：显式图形关系、分组和共享控件形成单元；单元按创建步骤组成内容块。比较图保持顶端对齐，控件保持在实际关联图形下方。说明和公式可以利用同一内容块的横向空间。

讲解过程中使用固定宽度策略和有序分栏，追加练习不会改变已有图形、控件坐标。结束时计算不同内容块宽度、按行/按列排列及换行边界的候选，使用与镜头相同的安全区域算法比较最终缩放，选择显示尺寸最大的候选，同分时选择占地更小者。顺序保持为按行或按列阅读；不按文本内容猜图形归属，不用课程名或特定节点 ID 分支。

每个步骤最多 5 种宽度与 1 种图文左右排列候选；各步骤可以选用不同宽度。确定性搜索最多 256 组组合，每组最多 7 个列高度和 32 个行宽候选；几何输入相同使用最多 24 项的缓存。变量值、用户缩放不进入几何缓存键，不触发布局搜索。窗口物理尺寸和界面遮挡才影响可用空间。未传入新 composition 参数的调用方保持原行为；inside/overlay 的原有回退保留。

### 完整边界与动态更新

宿主 `oll-lesson-runtime.tsx` 继续按课程归属收集白板节点、控件和练习，增加真实尺寸观察与几何变化通知。练习反馈增高、字体变化、窗口变化后，结束取景可以更新。镜头请求使用独立递增序号；不再因为 cursor 未变而把窗口变化后的请求判为重复。

边界完全相同时不重复取景。结束取景仍优先于练习局部取景。用户主动平移或缩放后，普通更新不抢回镜头；新增“查看整课”按钮主动恢复完整展示。课程重播会清除上一轮结束取景记录。

### 全景专用取景

OLL `camera.ts` 的 course 模式使用默认 24px 的安全边距，并继续避开宿主登记的遮挡；不沿用讲解镜头的宽留白。完整入框优先，不用讲解缩放下限强行放大到裁切内容。全景选择最大可容纳缩放，不再为了接近屏幕中心而接受较小的缩放。讲解镜头保持原有模式。结束旁白、右下角角色与连接提示也登记为遮挡；普通播放中的临时旁白保持原有行为。

### 手写保护

现有笔迹没有足够可靠的卡片锚定信息，因此不假定笔迹会随卡片移动。检测到卡片上的笔迹时，保守保留当时已有卡片及控件坐标；后续新内容放在已有内容之外。空白区域笔迹作为障碍。笔迹清空后解除保护。这个例外可能降低紧凑程度，但不会为优化全景把卡片与批注分离。

## 桌面与窄窗口实测

测试使用“开始互动”入口，包含手写工具栏、输入栏和练习反馈。第一课先答对练习，再检查结束画面。下表的缩放是卡片真实屏幕宽度与白板布局宽度之比，不是浏览器页面缩放。

| 课程 | 1920×1080 | 1440×900 | 700×1000 | 裁切卡片数 |
| --- | ---: | ---: | ---: | ---: |
| 水平截线与等高线 | 1.198 | 0.874 | 0.672 | 三种尺寸均为 0 |
| 偏导数 | 1.038 | 0.757 | 0.564 | 三种尺寸均为 0 |
| 马鞍面与鞍点 | 0.838 | 0.611 | 0.465 | 三种尺寸均为 0 |

验收门槛预先固定：1920px 窗口缩放至少 0.75，1440px 至少 0.60；窄窗口要求完整入框，不承诺全课小字无需放大即可阅读。测试逐个检查可见卡片的屏幕边界及遮挡相交，不能用仅检查 DOM 存在代替。

截图和原始测量在同目录 `overview-evidence/`。测试还覆盖从窄窗口恢复宽窗口、手动缩放后保持镜头、练习高度变化及“查看整课”恢复。

## 验证与性能

- 桌面浏览器回归：24 项通过（微积分、一次函数、三角函数、字体与布局）。
- Android 显示模式：三课全景 3 项通过；这是浏览器模式检查，非 Android 真机测试。
- 用户预览端口 5173：最终三课全景与手写保护 4 项通过。
- 共享 OLL core/player/web-runtime：244 项通过。
- 应用宿主、角色组件和遮挡观察单测：121 项通过。
- learning-coach：165 项通过。
- 课程包：20 项通过。
- 应用 TypeScript 检查、三课共享 materializer 事件一致性检查通过。

本机 30 次布局样本、不含宿主附件与浏览器测量：三课未缓存 p95 约 1.18 / 9.56 / 10.86ms，缓存后 p95 约 0.110 / 0.124 / 0.168ms。记录见 `overview-evidence/layout-benchmark.json`。这些数值不代表线上总时延或浏览器完整重排耗时；本轮没有增加模型、网络、TTS 调用。

## 使用

刷新 https://127.0.0.1:5173 ，进入当前 0.2.1 课程，从头播放或重新开始。结束时应自动显示整课；手动缩放后可点右上角“查看整课”。无需删除课程包或下载新课程版本。旧学习会话和新实时课程使用同一套宿主与 OLL 逻辑。

依赖修改同时保存在 OLL 源码和应用、课程库、生成器的补丁/契约/锁文件中，不能只复制某一份 node_modules 作为交付。
