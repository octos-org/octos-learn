## 重启

当前前端和后端已运行。前端退出后，在本仓库执行：

```bash
scratch/e2e-camera-layout-20260928/start-web.sh
```

该脚本固定本次本地目录、HTTPS 5173 端口，并清除 OLL 源码 alias。2026-09-29 复核发现当前进程未携带课程目录变量，实际回退为公网旧课。现已把 `OCTOS_LOCAL_COURSE_PACK_ROOT` 写入 gitignored 的 `.env.local`，并经 HTTPS 接口确认九课中四门为本次修订版本；普通 `pnpm dev:https` 重启也会沿用本地复测目录。恢复公网课程输入时删除 `.env.local` 中该变量并重启。

若后端退出，按开发交接在 octos 仓库执行：

```bash
env -u OCTOS_SKILLS_PATH OLL_PROVIDER=gemini OLL_MODEL=gemini-3.6-flash \
  ./target/release/octos serve --host 127.0.0.1 --port 50080 --solo
```

不要重复启动占用同一端口的服务。生成脚本仅用于首次准备，会拒绝覆盖已存在的修订目录；已生成音频不需要再次付费重录。
