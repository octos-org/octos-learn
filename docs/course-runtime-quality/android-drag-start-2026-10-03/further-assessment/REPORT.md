# 进一步优化评估（2026-10-03）

用户确认当前拖拽性能已可接受，并允许得出没有进一步收益的结论。本轮只做一个可逆候选对照，未修改产品源码或安装新 APK。

## 候选与实验

缓存图片插入/移除会触发白板几何 MutationObserver，虽然图卡世界尺寸不变。临时包装 requestAnimationFrame，只在缓存活动期间跳过这一几何测量回调；其他回调照常执行，退出时补执行最后待测回调并还原原生 requestAnimationFrame。

当前真实场景为斜率课程、有 64 项已保存笔迹。每组开始临时将书写切换为浏览，结束恢复书写模式和原镜头。选取当前 DOM 校验为空白的触屏路径。四组按控制/候选/控制/候选交错，每组三次 650ms Android touch swipe；每次与上一阶段一样记录 rAF 和长任务，不强制读取逐帧 computed style。

| 组别 | 路径 | 跳过回调数 | 三次手势最大 rAF 间隔 ms |
|---|---|---:|---|
| [a1](a1.json) | control | 0 | 183.1, 139.1, 44 |
| [b1](b1.json) | skip | 2 | 187, 122.9, 36.2 |
| [a2](a2.json) | control | 0 | 169.9, 61.7, 47.4 |
| [b2](b2.json) | skip | 2 | 115.9, 111.5, 45.8 |

所有组的第三次手势都没有活动缓存帧，故不把它纳入缓存候选的定量收益比较。活动缓存的四个手势中，控制组最大间隔均值 138.4ms，候选 134.3ms；这是约 3% 的单次实验差异，样本少、组间不稳定，不能声称显著优化。总体活动帧中位间隔控制 26.4ms、候选 26.2ms。部分手势改善、另一些退化，保留当前正式 APK。

## 结论

这个低影响候选没有足够稳定的收益，不作为交付修改。本次不是证明渲染性能已到绝对上限；剩余长帧和间隙重排仍有分析空间，但进一步更大改动需要另做成本与效果评估。在用户已经接受当前性能的前提下，此处停止扩展优化范围。64 项笔迹前后相同，所有组的节点样式前后逐项一致，实验探针与原生 rAF 已还原，书写模式和镜头已恢复。
