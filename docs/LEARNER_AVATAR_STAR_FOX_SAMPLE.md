# 星狐三维小样 v0.1：本项目直接制作

日期：2026-11-02。用户明确没有其他制作人员，希望由当前协作直接制作。本轮已从调研转为亲自制作并接入，**不再把寻找外部美术团队作为开始制作的前提**。

## 实际交付

- 可编辑的代码建模源：`src/learning/avatar/star-fox-model.ts`。头部轮廓、橙色曲面发束、立耳、奶油色脸颊、琥珀眼睛、学院服胸像与星形胸针均直接制作，没有购买模型、上传参考图到第三方服务或调用付费模型生成 API。
- 生成脚本：`scripts/create-star-fox-model.ts`，使用已有 Three.js 导出标准 GLB。当前源工程是参数化 TypeScript，**没有提供 Blender 手工雕刻工程，也不是由概念图自动恢复出的精确三维模型**。
- 运行资产：`public/teach-avatars/star-fox/sculpt-v0.1/model.glb`、`rig.json`、`asset-info.json`。版本 `0.1.0`，文件 **1,623,264 字节**；SHA-256 `c424a99d33ed8952e6dc7b071a3d93cb7ca2f0d9493e0474e0bb41b225f89a3d`。
- 33,305 个顶点、56,652 个三角面、36 个网格、68 个网格形变目标；合并静态同材质几何、保留索引、去掉无用 UV，不依赖纹理或外部资源。这是资产统计，不能直接换算为大屏 FPS 或实际内存。

模型重建命令：

```sh
pnpm exec vite-node scripts/create-star-fox-model.ts
pnpm exec vite-node scripts/check-avatar-rig.ts public/teach-avatars/star-fox/sculpt-v0.1/rig.json public/teach-avatars/star-fox/sculpt-v0.1/model.glb
```

## 表情与接入

实现 21 个通道：开颌、闭唇、噘嘴、漏斗嘴、左右微笑、左右眨眼、眉心上提、左右眉毛下压/外侧上提，以及左右眼各四个视线方向。其余 31 项在映射中明确标为不支持；没有用空形变凑齐 52 项。

嘴部包含独立唇缘、口腔曲面、下颌、上齿和舌部。闭唇输入优先抑制开颌，避免两个相反指令相加后仍张嘴；这是小样运行规则，不是完整的协同发音或全组合修正系统。眼皮使用覆盖眼球的实际曲面，不缩放整个眼球来伪装眨眼；侧视和极端组合仍需进一步打磨。

`star-fox-asset.ts` 读取本地版本化 GLB，先检查资源限制及 SHA-256，再由 GLTFLoader 解析并复用现有命名绑定。当前加载配置仅接受无扩展、无图像、无外链的本项目小样，不能视为已支持任意第三方模型。离开页面/超时会取消加载，解析迟到的模型会释放；退出销毁几何、材质和渲染器。

`AvatarStage` 已改用该资产，试验室、配音排练、作品预览和下载课包播放器共享此模型。加载错误不静默换回旧角色；播放器仍保留声音与白板。15 秒加载上限，加载时有明确状态。定格与暂停回放停止持续渲染，换表情后按需重绘。

课包 v2 本身仍只携带嘴型参数，**未嵌入该模型或绑定版本**。当前角色是应用附带资产，不能把它描述成课程包可独立携带的完整角色。

## 验证与边界

- 完整单元测试 **188 文件/1627 项通过**，增加实际 GLB 解析/绑定、每个映射均有非零形变、哈希错配拒绝、外链资源拒绝、闭唇优先及定格不启用摄像头的验证。
- TypeScript、生产构建、中英消息检查通过：80 UI 文件、2675 对消息。修改模块 ESLint 零错误、零警告；既有构建大分包提示保留。
- [Khronos glTF Validator](https://github.com/KhronosGroup/glTF-Validator) 的 npm `2.0.0-dev.3.10` 在本机临时目录检查实际文件：0 error、0 warning、0 info。工具没有加入项目依赖；[验证报告](avatar-animation-phase-a/star-fox-sculpt/gltf-validation.json)保存在仓库。现有项目绑定契约检查也通过。
- 没有使用真人照片、声音、面部捕捉或付费语音。没有完成 iPhone/iPad 或安卓触摸大屏实测。
- 这是可运行的第一版美术小样，偏卡通玩偶质感；仍有发束块面、口鼻比例、下颌形体和侧面组合衔接需要修正。与批准的二维概念图在毛发、服装细节和比例上仍有明显差别。几何有效、通道能动与美术自然度分别验收，不能据此宣称达到苹果效果。

下一步优先按真实截图打磨脸型、发束和下颌，再增加眼皮/眉眼组合与精细发音。外部制作仍是可选加速路线，详见[先前调研](LEARNER_AVATAR_PRODUCTION_RESEARCH.md)；用户当前没有美术人员不再阻止程序与模型迭代。
