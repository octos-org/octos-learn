本版汇总 v0.1.0 之后已经合并并验证的产品改动：Android 白板导航、滑块与三维旋转性能，原生笔迹移交和初始化坐标修复，课程画面确定性复用及附件布局，九门内嵌课程与目录、历史恢复、应用抽屉和公网 demo。

用户于 2026-10-04 确认新版 APK 抬笔不再位移，并授权合并剩余可合并产品 PR 和发布新版。OLL #22 与 Octos Learn #47 均已通过 CI 并合并。生成课程时现有居中取景行为保留；TypeSafe/Jev 与 TTS 行为保留，生产 `OCTOS_LEARN_TTS_PLATFORM_TOKEN_DISTRIBUTE=1` 不变。

Android 包名 `cc.pitun.learn`，versionName `0.1.1`，versionCode `32`，最低 Android 8.0。延续既有安装包签名，使用覆盖安装保留用户数据。最终 APK 必须从干净的已合并 main 构建，附带 SHA-256 和内置 build-info；不从独立目录构建。

## 发布验证边界与跟踪项 REL-011-E2E

本次版本准备不新增功能。九项人工 E2E 清单不宣称在最终版本逐项重新执行：文字/多课程/选择辅助/回放/恢复沿用已记录的验证和本轮电视测试；真实语音、摄像头上传、选区直接语音和模糊输入没有重新执行完整人工路径。自动浏览器 fixture 不代替真实模型、麦克风和摄像头验收。

发布例外依据是用户对已测试阶段的发布授权；保留上述验证范围，不能将其写成“九项最终版本人工 E2E 全通过”。跟踪项 **REL-011-E2E** 的负责人为发布维护者 `alan0x`，后续在下一个涉及输入、认证或生成路径的发布前补齐九项真实设备人工清单，并记录模型、provider 和确切版本。本仓库 GitHub Issues 已禁用，因此在此维护跟踪项。此项是覆盖范围跟踪，不是已确认功能故障。

用户明确保留的取景行为不作为本版待修缺陷；不修改提示词、不移动用户保存的笔迹、不升级未经本轮验证的上游 PR。
