# 给手势白板研究 agent 的 prompt

当前头像技术：**MediaPipe 实时动作捕捉 + Canvas 2D 插画局部纹理/网格变形**。手势对应同一系列的 **MediaPipe Hand Landmarker**。

---

请基于 OctosLearn 项目，研究并制作“通过摄像头识别手势，在现有数字白板上书写、画图”的小样。

仓库是 `octos-learn`，参考分支是 `codex/avatar-capture-prototype`；星狐确认版提交为 `af2b1f08`。请建立自己的分支，最好用独立 worktree，例如 `codex/gesture-whiteboard`。头像 agent 正在原分支扩展角色，不要直接修改其工作区。不要自行合并或部署。

先阅读 `AGENTS.md`，检查现有白板输入接口，以及 `src/learning/avatar` 下已有的 MediaPipe 手部捕捉代码。当前头像采用 MediaPipe 动作捕捉 + Canvas 2D 驱动；本任务重点使用 Hand Landmarker 追踪手指，不需要图像生成模型。

请比较食指隔空书写、拇指与食指捏合落笔等交互，选择一种适合第一版的方案。解决摄像头镜像、手部坐标映射到白板、画面缩放和平移、轨迹抖动、落笔/抬笔、手部遮挡或丢失时断笔的问题。避免手移动时一直误画；复用白板已有笔画、撤销和保存能力。

先完成可运行的小样与模拟轨迹验证，报告效果、延迟和局限，明确隔空书写能否达到实际可用程度。识别尽量在设备本地运行，不上传摄像头视频。保持现有账号、服务和端口，不要求用户立即测试设备。

与当前头像制作工作并行，避免修改其素材和渲染代码；如需共用文件，先说明改动边界。把方案、实际结果和后续步骤记录到 `docs`，并更新索引。
