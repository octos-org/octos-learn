# 耳发随头动与张嘴线条：第三轮修正

日期：2026-11-03。用户在浏览器试用后提出两点：①耳朵动作不明显，且耳朵和头发没有随头部动作而动；②张嘴时嘴唇线条歪、像锯齿。分支 `codex/avatar-capture-prototype`，未合并、未部署。

## 原因

- **头发不随头动**：上一版给头发加的静态偏移方向与头部位移几乎相反（头右移 ~10 px，发梢左移 ~8 px），转头后发梢基本停在原地；歪头“重力”方向也反了。头发弹簧只有 3–5 px 的余量，几乎看不到滞后。
- **耳朵不随头动**：耳朵只随整块头部刚性平移，没有滞后；转头时的耳平面投影只有 0.2 且左右方向反了（转向侧的耳朵反而变宽）。待机“转耳”只做 0.25 左右的横向缩短，正常尺寸下几乎看不出来。
- **嘴线歪/锯齿**：张嘴时下唇沿用了上唇“ω”形画线的形状，而且张开高度逐列取自口腔素材的上下边界，导致下唇呈 W 形、逐列台阶，边缘还带出画线下半部分的灰边。

## 现在的做法

`painted-secondary-motion.ts`：

1. **耳朵滞后跟随**：对头部 yaw/pitch/roll 做一阶滞后（时间常数 160 ms），耳朵在画面平面内绕耳根随“头已经动了、耳朵还没跟上”的差值倾斜，最多约 0.2 rad，并按耳长限制耳尖位移（≤30 px），然后单调追上、**不回弹**。不是弹簧甩耳。
2. **转头时耳朵侧转**：转向一侧的耳朵变窄并向外张开（更接近侧面），另一侧耳朵朝向观众、略微变宽。耳廓变窄时同时向外张开（`paintedEarTransform`），待机“转耳—保持—回正”也因此看得出来。
3. **头发惯性**：发梢是被头部拖动的世界坐标阻尼弹簧（ω=8，阻尼 0.58）：头动时落后、停下后越过一点再回到原位；发根随头，发梢动得多。歪头时发梢略向下垂（重力），点头有轻微上下余动。
4. **转头立体感**：脸部中间比轮廓多移动最多 9×0.45 px，读起来像转头而不是整块平移；轮廓（裁切边的头发、耳朵）仍刚性。

`painted-fox.ts` 张嘴：

- 上唇保留原画“ω”线，张嘴时只略抬；下唇改为一条光滑弧线（两嘴角之间），闭合到张开平滑过渡；张开区域按像素与开口区间的精确覆盖做抗锯齿，不再逐列台阶。
- 口腔纹理只按平滑后的上下边界取色，不再决定嘴形；下唇画一条与原画线同色、两端渐细的细线。
- 闭嘴、眨眼、皱眉等不张嘴的状态与用户认可的星狐（`af2b1f08`）逐像素一致；张嘴姿态只在嘴部区域不同（用户要求修改的部分）。

`illustrated-avatar-stage.tsx`：耳发跟随改用渲染时钟（摄像头帧约 20 Hz 且时间戳重复，用它会一顿一顿）；头停下后耳发还在追赶时继续绘制，静止后才停。

## 边界

仍是正面画稿上的二维近似：没有侧/背耳素材，耳朵不能真正转到背面。张嘴仍是基础开合，不是音素口型。**用户尚未看过本轮效果**；没有真人摄像头、iPhone/iPad 或安卓大屏验证。正式课程播放里耳发待机动作仍关闭（头动跟随在播放中没有头部输入，所以不受影响）。
