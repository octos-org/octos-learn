# 星图学院：世界观设定（草案）

日期：2026-10-24。状态：草案，等用户挑选和修改。

用户的决定：游戏化方向以魔法学院为世界观；面向小学、初中、高中；主要设备是电脑浏览器和大屏触摸电视；美术素材用 AI 生成。

这份设定的目的，是让三件事有同一个来处：老师的角色、知识点星图、成就。名字和台词都是初稿，可以整体替换。

## 1. 一句话

**星图学院**建在天空的最高处。世上所有的知识，都化作夜空里的一颗颗星辰，可它们大多藏在**迷雾**后面。学生是新来的**星图学徒**，跟着导师一节课一节课地驱散迷雾、点亮星辰，画出只属于自己的星图。

## 2. 世界的基本设定

| 设定 | 内容 | 对应到产品 |
|---|---|---|
| 星辰 | 每一颗星是一个知识点。星辰本来就在那里，只是被迷雾遮住 | 知识点目录（os-taxonomy，约 1800 个） |
| 星座 | 有前后关系的星辰连成星座：先点亮前面的星，后面的星才更容易看清 | 知识点之间的前置关系 |
| 星域 | 同一学科、同一领域的星辰聚在一片星域，例如“数之星域”“万象星域” | 学科和领域分组 |
| 迷雾 | 还没探索的地方。迷雾不是敌人造成的“损失”，只是“还没去过” | 地图上没有记录的知识点 |
| 封印 | 每颗星外面有一层封印，要靠练习来破除 | 课后练习 |
| 星图 | 每个学徒自己的那一份夜空 | 学习地图 |

关于“敌人”：昨晚讨论过，知识本身不能是敌人。这里的对手是**迷雾**，它代表“还不知道”。学生驱散的是迷雾，点亮的是星辰，星辰最后成为学生自己的光。迷雾不会因为学生不学而回来，也不惩罚任何人。这和现有的规则一致：学习记录只说“还没一起走过”，从不说“你不会”或“你忘了”。

## 3. 学徒（学生）

- 入学时是**见习学徒**。按年级分为三个学部，但不设门槛，任何学部的学生都可以去任何星域：
  - **启明部**（小学）：星辰亮度柔和，导师说话更短、更多比喻。
  - **星辉部**（初中）：现在的数学内容主要在这里。
  - **星穹部**（高中）：需要补充高中目录后开放更多星域。
- 学徒没有等级和排名，也不和别人比较。成长体现在自己的星图和成就册上。

## 4. 导师（老师）

两位导师沿用现有的性格设定（价值观、遇到错误怎么办、表扬方式、口头禅都不变），只是给了他们在学院里的身份。台词风格保持一致，只是换上学院里的说法。

### 阿澜：观星塔的推理导师

- **身份**：观星塔的导师，负责教学徒“读懂星辰的轨迹”，也就是找到每一步的理由。
- **形象**：深蓝色长袍，银色细边眼镜，手里总有一本摊开的星图笔记。身边漂浮着一盏小小的星灯，学徒想清楚一步，星灯就亮一点。
- **标志物**：问题收藏匣。对应他现在的口头禅“值得收藏的问题”，遇到好问题，他会把它“放进收藏匣”（只是说法，不真的保存，和现有规则一致）。
- **代表色**：深蓝、银白。
- **法术风格**：精确的星轨和几何光线，例如把斜率画成一道从原点射出的光。

### 豆豆：幻象工坊的比喻导师

- **身份**：幻象工坊的导师，擅长把难懂的东西变成眼前的幻象，比如一段山路、一场球赛。
- **形象**：珊瑚色短披风，头发上别着一颗会变形的小星星，口袋里总装着各种小道具。
- **标志物**：万象口袋，一次只掏出一个比喻（对应现有规则“一次只用一个主要比喻”）。
- **代表色**：珊瑚橙、暖黄。
- **法术风格**：生活场景的幻象，讲完马上收起幻象，回到黑板上的数学。

### 以后的导师

预留几个学派，等需要时再加：例如“咒文塔”（语言、英语）、“万象温室”（科学）、“时光书库”（历史）。每加一位导师，都按现有的性格卡片补齐设定，再生成立绘。

## 5. 学习动作和世界里的事

| 学生做的事 | 学院里的说法 | 星图上的变化 | 依据（程序可以核对） |
|---|---|---|---|
| 提一个问题 | 向导师求教，翻开一卷新的星图卷轴 | 相关星辰周围的迷雾变淡 | 提问记录和分析结果 |
| 看完讲解 | 听导师演示法术 | 星辰显现微光：**已探索** | 实际播放完成的片段 |
| 做练习 | 尝试破除封印 | 封印出现裂纹：**正在练习** | 作答记录 |
| 不看提示做对 | 亲手破除封印 | 星辰点亮：**做出来过** | 不看提示达到要求 |
| 不同的日子回来练习 | 再次巩固这颗星 | 星辰升级，外面多一圈星环（等级以后定） | 在不同日期的练习记录 |
| 隔一段时间回来 | 故地重游 | 星辰闪一下 | 距离上次学习超过 14 天 |
| 打开周报 | 读导师写的学院周记 | — | 周报和评语 |
| 看“下一步建议” | 接受导师的委托 | 委托指向的星辰轻轻闪烁 | 地图状态和前置关系 |
| 获得成就 | 被授予学院徽章 | 徽章放进成就册 | 成就规则 |

几条不能破坏的原则：

- **点亮不等于掌握。** “做出来过”只说明亲手做对过一次。星辰点亮后不会熄灭，也不会因为答错而变暗。
- **所有奖励都来自真实的学习记录**，不来自登录天数、停留时间或点击次数。
- **答错没有惩罚。** 封印没破就是还没破，下次再来。
- **没有排名，也没有和别人的比较。**

## 6. 成就（学院徽章）

现有的四个成就放进学院里的说法：

| 现有成就 | 学院徽章 | 说明 |
|---|---|---|
| 初来乍到 | 第一缕星光 | 第一次看完一段讲解 |
| 亲手搞定 | 破印者 | 第一次不看提示做对练习 |
| 常客 | 守星人 | 在三个不同的日子回到同一颗星 |
| 老朋友重逢 | 故地重游 | 隔了 14 天以上回到同一颗星 |

扩充的方向（具体名单另写）：

- **收集类**：点亮某个星座的全部星辰，点亮一片星域的十颗星。
- **隐藏类**：例如“深夜观星者”（夜里学习），或者“推翻导师”（指出导师讲错的地方，对应现有的“老师在这节课里讲错”情境）。
- **纪念类**（代替会绝版的限时成就）：例如“星落节”期间学习会得到当季纪念章。纪念章错过了就是错过了，但不会让人觉得吃亏，也不影响其他成就。

## 7. 美术方向（AI 生成）

AI 生成最大的难点，是同一个角色在多张图之间保持一致。建议的做法：

1. **先给每位导师写一份固定的描述**：脸型、发型、服装、配色、标志物，以及不能变的细节。每次生成都使用同一份描述。
2. **先生成一张“定稿”立绘**，作为之后所有图的参考图。
3. **再生成表情差分**：思考、讲解、惊喜、夸奖、等待。上课时按情境切换，例如学生做对练习时换上夸奖的表情。
4. **整体画风统一**：建议用柔和的赛璐璐风格，深蓝夜空做底色，星光用暖金色。这个风格要在大屏电视上看得清楚，也不能太花，干扰到白板。

## 8. 大屏触摸电视和电脑

- 星图要能用手指拖动、双指缩放，也能用鼠标滚轮和拖动操作。
- 大屏上星辰和文字要足够大，适合站在一两米外触摸。
- 动画要有“减少动画”的选项，也要注意电视的性能。

## 9. 需要你决定的事

1. 学院和导师的名字：星图学院、观星塔、幻象工坊，用不用，或者换成别的？
2. 三个学部的划分和名字（启明、星辉、星穹）。
3. 美术画风：柔和赛璐璐，还是别的风格？
4. 先做哪一块：我建议先做**星图原型**（不依赖美术，用现有的地图数据）；同时用 AI 生成**一位导师的定稿立绘**，看风格对不对。
