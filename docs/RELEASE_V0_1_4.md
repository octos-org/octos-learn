# Octos Learn v0.1.4

用户框选手写公式后说“这种公式应该如何解，请给我上一节课”，前端的 Jev 文字预判可能返回 `clarify`，在 Learning Coach 读取选区图片之前提前结束请求。预判只收到文字及是否存在选区/摄像头画面的标记，没有图片内容。

本版在文字预判返回 `clarify` 且请求带有选区或摄像头视觉上下文时，将请求交给已有的图片处理流程。无视觉上下文的澄清和既有噪音过滤保留。修复适用于语音和文字输入，不匹配特定公式或话术，不修改生成提示词、选区课程/局部问答分流规则，也不增加模型往返。课程模型仍在已有的首次图片请求中决定生成课程、澄清或忽略。

## Android 与依赖

Android 包名 `cc.pitun.learn`，versionName `0.1.4`，versionCode `35`，最低 Android 8.0。正式 APK 从合并后的干净 `main` 构建，沿用既有签名，以保留数据的覆盖方式更新。九门内嵌课程快照仍为 `curated-e2e-closeout-2026-09-30`，上游依赖不变，确切版本见 `learning-stack-bom.json`。

正式 release 附带 APK、SHA-256 和验证 JSON。发布后重新从 GitHub release 下载 APK，核对与构建产物一致，再复制到 U 盘根目录并安装到本地皓丽大屏；此轮交付不包含公网服务器部署。
