# 星狐单耳绘制姿态动画试验

更新：2026-11-04。用户反馈当前耳朵仍像图片扭曲，授权验证“绘制不同朝向，再做动画过渡”。本轮先做画面左耳，保留原网格耳作为对照；右耳、嘴部和课程接入不扩展。

> **最新：v0.1 被用户指出明显脱节，已进入 v0.2 修正。** 原因是生成耳朵上覆盖了旧的固定白毛连接带，固定前景中也混入内耳；转到背面时这两层仍停在原位。旧报告“根部 RGB 差 0”保护的恰好是这块错误残留，不能说明衔接自然。v0.2 删除固定耳毛层，整耳绘图放在按实际头发轮廓描出的前景之后。当前预览默认加载 v0.2，尚未得到用户确认。

## 判断标准

不能只靠网格正面积或无裂缝判定成功。要能看到朝向变化带来的内耳、背面及轮廓变化，观察静止保持时有无纹理跳变、过渡时有无双轮廓，并保留失败与剩余局限。**当前单耳对照程序/素材已交付，不代表用户认可新路线或动画已达到成品质量。**

## 如何查看

原地址 `https://127.0.0.1:5173/teach/avatar-2d`，星狐、默认勾选“使用新版双耳与发束”和“左耳使用绘制姿态动画（试验）”。

1. 点击“播放左耳转向对照”，头部、右耳和发束保持，画面左耳单独由正向转向外侧/后侧再回位；无摄像头。
2. 演示中切换“左耳使用绘制姿态动画（试验）”，同一单调时间线驱动新绘图和旧网格，可在同一输入下比较。绘图加载期间画面会短暂显示加载状态，不启动摄像头。
3. 拖动左耳滑块可逐姿态检查；新动画范围 0..1，仅实现向外转，旧网格仍为 -0.4..1。
4. 点击“回到自动跟随”，清除试验演示和局部定格，恢复原自然动作选择；也可开启摄像头。动画朝向沿用现有头姿/次级动作映射，**没有动物耳朵捕捉器**。

角色切换、开始录动作、进入其他表情/摄像头模式会结束单耳演示；录制时禁用切换。人工演示不写入脸部动作文件。默认正式课程舞台和配音排练没有启用这个单耳试验。

## 实现与素材

- `painted-ear-turn.ts`：从统一图集选择一个姿态，使用普通 `drawImage`；本路径不调用耳朵局部网格，不做运行时非线性拉伸，不叠加两张姿态图。
- `prepare-ear-turn.ts`：复用原生成图集，拆成 12 张，统一缩放并按隐藏耳底对齐，生成 1024×960 整耳图集；**不再叠加固定原画耳根**。另生成只包含头发的前景，实际描绘发束和小卷尖的边缘，白色内耳不留在前景中。原画和生成源像素保留，通过原生路径遮罩切分，没有新增 AI 调用。
- `painted-local-rig.ts`：只有加载了试验图集的实例替换画面左耳。右耳、发束和嘴型保持原实现；试验未开启时不增加运行图片。
- `illustrated-avatar-stage.tsx`：试验仅在启用局部绑定的星狐上加载图集和独立头发遮罩两张图；两者全部就绪才绘制，遮罩加载失败不使用旧白毛前景替代。切换、销毁会解除图片和帧回调。演示复用舞台时钟，没有独立未清理的计时器。
- `avatar-lab-page.tsx`：新旧开关、循环对照演示和定格检查，不新增捕捉请求。

当前素材在 `public/teach-avatars/star-fox/ear-turn-v0.2/`：`poses.png` 是整耳运行图集，`foreground.png` 是只含头发的遮罩，`registration.json` 是逐帧对齐记录。v0.1 的 `poses-generated.png` 为生成原件，使用**内置 imagegen**、透明背景；完整最终提示词保留在 [v0.1 生成记录](../public/teach-avatars/star-fox/ear-turn-v0.1/asset-info.json)，当前处理与哈希见 [v0.2 记录](../public/teach-avatars/star-fox/ear-turn-v0.2/asset-info.json)。生成图近乎透明的噪点（alpha ≤ 7/255）仅在准备图集时去除，其余透明度与抗锯齿保留。v0.2 没有新生成或外部图片 API 调用。

## 验证与发现

- 全量 **207 文件 / 1730 项**单元测试通过，包含页面、舞台和新耳逻辑 3 文件 / 25 项。构建、修改代码 lint、i18n（84 UI / 2878 对）通过。
- 原双耳/发束/口型绘制约束在当前源码复验通过，新试验关闭后仍保留基线行为。
- 新耳 12 个图形姿态，在 3 种头姿下扫描 135 个参数输入：连接区露纸 0、衣服差异 0、保护的头发内部差异 0。全部姿态的耳/发遮挡重叠区域最低透明度 252/255。背面姿态的错误白毛探针从原版 9 个命中降为 0，前景在这三个确定内耳点的 alpha 为 0。
- 新回归明确运行两组反例：只恢复旧前景、只恢复旧耳根补片，分别重新命中 3 和 1 个错误白毛点。不能只把图片弄平滑或固定住原耳根就通过。耳部颜色在原连接区允许且必须随朝向变化，不再沿用错误的“所有耳根 RGB 不变”要求；头发与连接覆盖仍有各自约束。
- 最初浅色像素计数混入纸面颜色的历史问题已保留；浅色内耳上部探针从 1909 降到 249，此指标未覆盖用户指出的下部白毛残留，不能作为该缺陷修复的证据。

## 剩余限制与是否继续

新方法可以改变内耳/背面的显露；**仍不能据此判定它比原版更自然**。12 帧慢转时有逐帧感，相邻生成帧的毛纹存在变化；静止时选定同一张图，没有持续生成或纹理重绘。v0.2 已移除原固定耳毛，不代表生成耳形、饱满的耳底或全部转向已获得用户认可，未提供完全背面或前压/横倒动作。试验的中性耳形与原画不是逐像素一致。

若用户认可这个方向，下一轮重点是姿态轮廓和毛纹一致性、增加精绘中间帧，再考虑第二只耳；不能仅通过交叉淡化掩盖问题。本轮不采购 Live2D/Spine，也未重做三维角色。
