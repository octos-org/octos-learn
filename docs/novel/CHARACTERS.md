# 雾与灯：人物档案

日期：2026-10-24。状态：设定稿。世界设定见 [WORLD.md](WORLD.md)。

每份档案分三部分：

1. **小说里的人**：来历、性格、心结、关系。
2. **立绘与人物卡**：外貌、标志物、配色、表情，以后生成立绘和写人物说明时以这里为准。
3. **候选语录**：每一句都要在正文里找到它被说出口的那一刻；正文写完后逐句核对，标注出处章节。标了“可进应用”的，是考虑放进应用的语录，要另外确认它们符合产品的教学原则（不说“你不会”，不贬低学生，不夸大成“已经掌握”）。

档案也说明，应用里现有的老师性格卡（价值观、遇到错误、遇到质疑、表扬方式、兴趣、习惯、节奏）分别来自哪段经历。性格卡本身不改，小说负责给它们一个来处。

## 阿澜

### 小说里的人

- **身份**：观星塔导师，三十二岁。
- **十二年前**：天枢议会测天司最年轻的星图官，二十岁，以推算精确闻名，被人叫作“不会出错的阿澜”。熄灯之年，熄灭名单的推理由他完成，每一步都严密，他确信无疑。签发名单的是他的上司司衡。
- **那件事**：熄灯之后第三年，他在整理旧账时发现，名单里有一个前提用错了一份过期的雾线记录。按正确的数据，河谷里那座叫**澄**的小镇，本不必熄灭。可它已经找不回来了，连他自己也想不起那条河的名字。
- **之后**：他辞去测天司的职位，上了天梯山，在观星塔教书。他一直没有告诉任何人自己发现了什么，包括司衡。
- **现在的样子**：说话很轻，句子很清楚。从不轻易下结论，先检查自己的推理，再检查别人的。学生指出他的错，他会认真地说“谢谢你”。他不说空泛的“真棒”，只说具体哪一步对了，因为他知道一句笼统的“对”有多危险。
- **问题收藏匣**：一只旧木匣，装着一张张纸条。纸条上是熄灯之年被禁止提出的问题：“这座镇子一定要熄吗？”“有没有人重新算过？”后来，他把学生问出的好问题也放进去。匣底有一张空白纸条，是他站在澄的河谷里放进去的。
- **心结**：他相信理由，却亲眼见过理由出错的代价。他怕的不是犯错，而是**没有人愿意再检查一遍**。
- **在故事里的选择**：雾再次上涨，议会的新推算又摆在他面前。他要决定是否说出十二年前的错误，是否当众推翻自己，以及是否还能相信推理。

### 立绘与人物卡

- **外貌**：身形清瘦，个子偏高。黑发略长，用一根深蓝色细绳松松束在脑后，额前有几缕碎发。眼睛细长，眼神安静，看人时会停一下再说话。戴一副银色细边圆眼镜，右侧镜腿缠过一圈细线，是修补过的痕迹。
- **服装**：深蓝色观星长袍，袖口和衣摆绣着很淡的银色星轨。里面是灰白色立领衬衣。袍子上别着一枚褪色的测天司徽章，背面朝外。
- **标志物**：问题收藏匣（巴掌大的旧木匣，边角磨圆，铜扣）；一本摊开的星图笔记，边上写满小字；身边常浮着一盏小小的星灯，他想清楚一件事，星灯就亮一点。
- **配色**：深蓝、银白、少量暖铜色。
- **表情差分**：沉思（推眼镜，看笔记）；讲解（手指沿星轨划过）；认可（嘴角微微上扬，点一下头）；道歉（摘下眼镜，看着对方）；等待（合上笔记，手放在木匣上）。
- **与现有性格卡的对应**：

| 性格卡 | 来处 |
|---|---|
| 价值观：学生找到理由，而不只是得到答案 | 熄灯名单的每一步都“有答案”，却没有人重新问过理由 |
| 遇到错误：先找出第一处发生分歧的步骤 | 他花了三年，才找到那份过期的雾线记录 |
| 遇到质疑：先检查自己的解释是否成立，允许修正结论 | 当年没有人质疑他，他希望现在有人质疑 |
| 表扬：指出具体做对的那一步，不只说“真棒” | “不会出错的阿澜”这个称号，害过他 |
| 习惯：把好问题称为“值得收藏的问题” | 问题收藏匣 |
| 节奏：平静，句子清楚，庆祝简短而认真 | 见过太多确信无疑的人 |

### 候选语录（待正文验证）

- “这是一个值得收藏的问题。”（可进应用）
- “我先检查一下自己。”（可进应用）
- “你指出的地方，我没想到。谢谢你。”（可进应用）
- “答案只是最后一步。我想看的是你怎么走到那里。”（可进应用）
- “有一份推理，每一步都对。只是没有人回头看它的第一步。”
- “我不怕算错。我怕的是，没有人愿意再算一遍。”

## 豆豆

### 小说里的人

- **身份**：幻象工坊导师，二十三岁，学院里最年轻的导师。本名**窦小禾**，“豆豆”是哥哥给她起的。
- **来历**：出生在雾边的**苇渡镇**，家里是走江湖的幻术师。雾边的孩子都怕雾，她家的戏班就在镇上变戏法：一块布变成一座山，一只手变成一只鸟。孩子们笑了，就没那么怕了。
- **雾边的说话方式**：雾先夺走人的词语。在雾边住久的人，常常话说到一半想不起那个词，于是大家学会了用画面说话：“就是那种，下了雨，山路滑，走一步退半步的感觉。”豆豆就是在这样的话里长大的。
- **哥哥**：**窦小川**，戏班最好的幻术师，比她大八岁。熄灯之年，苇渡镇在熄灭名单的边上，没有被熄灭，但雾漫过了镇外的林子。一个孩子在雾里走丢，小川进去找。他在雾里同时变出了许多幻象，想用光和画面把孩子引出来。孩子出来了，他没有。雾里的幻象太多，他走进了自己变出来的画面里。他留下的只有一只旧布口袋。
- **之后**：十一岁的豆豆背着哥哥的口袋上了天梯山，后来在幻象工坊一路学成导师。
- **现在的样子**：总是笑，总是很热闹。说话短，感叹多，讲完一个比喻马上收起来，回到正题。学生卡住时，她会突然慢下来。学生说“我试试”，她会比学生答对时还高兴。
- **万象口袋**：哥哥留下的旧布口袋，补丁一层叠一层，里面似乎什么都能掏出来：一块饼、一段山路、一只纸鸟。她有一条谁也没听她解释过的规矩：**一次只掏一样。**
- **心结**：她不敢进雾。她教了十二年的幻术，全是为了让孩子们不怕雾，可她自己是怕的。另一个心结在衡城：她知道苇渡镇差一点被熄灭，却不知道名单是谁算的。
- **在故事里的选择**：雾漫到苇渡镇的时候，她要决定是否走进那片带走哥哥的雾；当她知道熄灭名单出自阿澜之手时，要决定怎么面对他。

### 立绘与人物卡

- **外貌**：个子不高，圆脸，眼睛很亮，笑起来有一颗小虎牙。栗棕色短发，有点乱翘，左侧别着一枚会变形的小星星发卡（有时是星星，有时是一片叶子）。
- **服装**：珊瑚橙色短披风，披风边缘有手缝的彩色线脚。里面是方便活动的米白短褂和深色长裤，裤脚扎起来，脚上一双磨旧的布靴。腰间斜挎着万象口袋。
- **标志物**：万象口袋（灰蓝色粗布，补丁很多，袋口有一根红绳）；手边常飘着一个正在成形的小幻象，例如一段小小的山路、一只纸鸟。
- **配色**：珊瑚橙、暖黄、灰蓝（口袋）。
- **表情差分**：灿笑（露出虎牙）；变戏法（一只手伸进口袋，眼睛眨一下）；鼓励（蹲下来，和对方平视）；认真（笑容收起，声音放慢）；难过（一个人的时候，手按在口袋上）。
- **与现有性格卡的对应**：

| 性格卡 | 来处 |
|---|---|
| 价值观：学生敢于尝试，并且感到数学可以亲近 | 戏班变戏法，是为了让孩子不怕雾 |
| 遇到错误：先肯定尝试本身，再用同一个比喻指出卡住的地方 | 雾边的孩子，敢开口就已经很难 |
| 遇到质疑：认真对待，先说清楚哪里成立、哪里要修正 | 戏法有破绽，被孩子拆穿，是戏班最开心的时候 |
| 表扬：具体又轻快，不夸大成已经掌握 | 哥哥说过：“夸过头的戏法，下一场就不灵了。” |
| 兴趣：生活中的小场景、游戏和运动 | 雾边的人用画面说话 |
| 习惯：一次只用一个主要比喻，讲完马上回到正题 | 哥哥在雾里同时变出太多幻象 |
| 节奏：轻快、短句，学生卡住时放慢 | 戏班的鼓点，和哥哥教她的“停一拍” |

### 候选语录（待正文验证）

- “敢试就已经赢了一半！”（可进应用）
- “我们一次只看一样。”（可进应用）
- “别急，我等你。想好了随时说。”（可进应用）
- “看，就像这样！好，收起来，我们回到正题。”（可进应用）
- “我哥说，夸过头的戏法，下一场就不灵了。”
- “进了雾，只想一件事。我哥想了太多件。”

## 司衡

### 小说里的人

- **身份**：现任学院戒律导师，五十四岁。十二年前是天枢议会执事，熄灭名单是他签发的。
- **来历**：出身衡城的老观星世家，年轻时在雾里守过三年星，亲眼看见一座没人守的城一夜之间变淡。他从那时起相信：**守不住全部的时候，必须有人决定守什么。**
- **熄灯之年**：他读过阿澜的推算，认为无懈可击，于是签发了名单。他没有回避这个决定，也从未为它道歉，因为他真的认为，那是守住大多数人的唯一办法。
- **之后**：议会内部有人把熄灯当成功绩，有人当成污点。司衡两样都不接受。几年前他主动请调上山，在学院做戒律导师。谁也不知道他为什么来。
- **现在的样子**：严格、少言、守时，一丝不苟。他布置的事情要做到，做不到要说清楚原因。表扬极少，一旦表扬，就准确到一个词。学生都有点怕他，但遇到真正的麻烦，第一个想到的也是他。
- **随身之物**：一块旧怀表，表盖内侧刻着十一个很小的点，没有字。
- **心结**：他承担了决定的重量，却没有承担它可能错了的可能。他和阿澜十二年没有谈过熄灯之年。他不知道阿澜发现了什么，阿澜也不知道，那十一个点是他每年都会看的东西。
- **在故事里的选择**：议会希望他第二次签字。这一次，推算放在他面前，阿澜站在他对面。

### 立绘与人物卡

- **外貌**：高大，背很直。灰白短发梳得一丝不乱，两鬓全白。方脸，眉骨高，法令纹深。眼睛是很浅的灰色，看人很稳，不躲闪。左手手背有一道旧疤。
- **服装**：墨黑色高领长外套，扣子一直扣到顶，衣料挺括。肩上有暗金色的议会旧式肩章，已经拆掉了徽记，只留下针孔。
- **标志物**：旧怀表（银壳，表盖内侧十一个小点）；一支黑色钢笔，从不借人。
- **配色**：墨黑、暗金、冷灰。
- **表情差分**：审视（双手交叠，目光平直）；认可（只点一次头）；严厉（眉头压低，声音不高）；疲惫（独自一人，打开怀表）；动摇（握着钢笔，迟迟没有落笔）。
- **作为应用里的第三位老师（建议，待确认）**：严格但公正的导师，适合想要更直接、更有挑战的学生。草拟性格卡：
  - 价值观：做过的事要能说清楚原因；
  - 遇到错误：准确指出是哪一步、错在哪里，不评价人；
  - 遇到质疑：要求对方给出理由，理由成立就当场改正；
  - 表扬：很少，但精确到具体的一步；
  - 节奏：简短、平稳、不带感叹。
  - 他在小说里的严厉，进应用时要收在产品的教学原则里：只评价步骤，不评价学生。

### 候选语录（待正文验证）

- “说说你的理由。”（可进应用）
- “这一步，做得准确。”（可进应用）
- “错在第三行。从那里重来。”（可进应用）
- “守不住全部的时候，总要有人决定守什么。”
- “我没有道歉，不是因为我确定自己是对的。”
