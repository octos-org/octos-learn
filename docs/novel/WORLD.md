# 雾与灯：世界设定

日期：2026-10-24。状态：设定稿，供小说写作使用；用户确认方向（“这个方向对了，很有感觉”）。

这本小说是星图学院的“设定集”：用文学的方式写这个世界和老师们的经历，不讲课程，不服务教学。老师的人物说明、经典语录和立绘细节，都要在小说里找到出处。人物见 [CHARACTERS.md](CHARACTERS.md)。

## 1. 雾

没有人知道雾从哪里来。最早的记载只有一句：“那年秋天，河谷里起了雾，三天没散。散了以后，下游的人说不出那条河叫什么。”

- **雾不伤人，只让人忘记。** 走进雾里的人，先忘词语，再忘名字，最后忘记自己为什么要走进来。被雾吞过的东西还在原地，可是没有人记得它。河床还在，卵石还是湿的，只是谁也想不起那是一条河。
- **被忘记的东西会慢慢变淡。** 一座没人记得的镇子，屋子会一天比一天模糊，像隔着一层水看。过几年，路过的人只看见一片空地。
- **雾有涨落。** 平常它待在低处的山谷和荒原里，像一层安静的白。每过一些年，它会涨起来，一夜之间吞掉几个村子。
- **雾里有幻影。** 人在雾里想得越多，雾就把念头变成影子。所以雾边的人有一句老话：“进了雾，只想一件事。”
- 雾怕光，但不是普通的光。

## 2. 星图

能对抗雾的，是**星图**。

- **观星者**把世间的一样东西，对应到夜空里的一颗星。对应的方法叫**“看见”**：观星者必须真正弄懂这样东西，它是什么、从哪里来、和什么相连，然后把这份理解写进星图，天上就会亮起一颗星。
- **星亮着，东西就不会被雾带走。** 雾可以漫过一座有星的城镇，退去以后，人们仍然记得它的名字。
- **星要人守。** 一颗星需要有人记得它为什么亮。守星的人老了、死了，或者自己也被雾碰过，星就会暗下去。所以星图不是写完就结束的书，而是要一代代人接着读、接着懂的东西。
- **星与星相连。** 一样东西总和别的东西有关：河连着镇，镇连着路，路连着另一座镇。星图上相连的星互相照着，一颗暗了，旁边的也会跟着暗一点。观星者管这叫**星座**。
- **守得住的星是有限的。** 观星者就那么多，人能真正懂的东西也有限。这是整个世界最根本的困境。

## 3. 星图学院

学院建在**天梯山**上。雾从来涨不到那么高。

- 它最早不是学校，而是**守灯处**：几十个观星者守着一张越来越大的星图。后来人们明白，星图要靠下一代人来读，守灯处才开始收学徒。
- 学院里有几座塔和工坊，各自看世界的方式不同：
  - **观星塔**：推算星辰的位置和关联，讲究每一步都有理由；
  - **幻象工坊**：用幻术把难懂的东西变成眼前的画面，最早是为了给雾边的孩子壮胆；
  - 其他塔，等故事需要时再写。
- 学徒按年纪分在**启明部、星辉部、星穹部**。星穹部那一圈，是学院一直想画却还没画完的天空。
- 学院有一个规矩：**星图上不排名次。** 这条规矩是熄灯之年以后才定下的。

## 4. 天枢议会

掌管星图的是**天枢议会**，设在山下的旧都**衡城**。

- 议会决定哪些地方派观星者、哪些星优先守护、学院的人和钱怎么分。
- 议会里有个**测天司**，专门推算雾的走向和星图的承受力，是全国最好的星图官待的地方。
- 议会的人大多不坏。他们面对的是一个真实的问题：雾在涨，人手有限。

## 5. 熄灯之年

十二年前，雾涨得前所未有地高。

议会的测天司算出：照这样下去，十年内星图会因为守不住而大片崩塌，相连的星一颗带着一颗暗下去，连最重要的城市也保不住。

议会做了一个决定：**主动熄灭一部分星**，切断它们和其他星的连接，把守护的力量集中到“最重要的”地方。

- 熄灭的名单由测天司推算，议会执事签发，学院执行。
- 那一年，有十一座镇子、两种方言、一条河，以及许多人的名字，被亲手熄灭了。雾随后漫过这些地方，再退去时，世上已经没有人记得它们。
- 那一年雾果然没有再涨，衡城和学院都保住了。
- 但是没有人能证明，如果不熄灯，星图真的会崩塌。

学院因为这件事分裂过一次。熄灯之后，学院定下了“不排名次”的规矩；也有人离开学院，再没回来。十二年来，议会和学院都很少再提这一年。

## 6. 现在

**雾又开始涨了。**

山脚的几个村子已经在夜里看见雾爬上田埂。测天司送来一份新的推算，和十二年前那份很像。议会派人上山，带来一句话：

**“也许，需要再熄一次灯。”**

小说就从这里开始。

## 7. 写作约定

- **不解释规则**。世界的规矩通过人物遇到的事显现，读者自己拼出全貌。
- **没有纯粹的坏人**。议会的选择有它的道理，学院的反对也有代价。
- **雾不是怪物**，是一种安静的、无法讨价还价的东西。恐怖来自遗忘，而不是来自袭击。
- **时间线**：现在的故事，与十二年前熄灯之年的回忆交替进行。熄灯之年定在十二年前，是为了让人物现在的年纪和已有的老师形象、声音相符（阿澜三十二岁、豆豆二十三岁）。
- **基调**：克制、具体、有温度。允许悲伤，不煽情；允许温暖，不甜腻。
