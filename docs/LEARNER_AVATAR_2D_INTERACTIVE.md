## 聊天内的直接互动

为避免再次只给静态展示，本轮另提供聊天内可直接拖动的二维控制：开口、微笑、左右眼、抬眉、歪头及四种定格姿态。该版本不访问相机、音频或网络 API；它用于当场看控制效果，完整捕捉/录制仍在上述本机应用入口。

聊天内容使用与应用相同的 `drawIllustratedFox` 函数，嵌入 600×656 的透明底稿副本。HTML 约 497 KB，无网络资源依赖；参数状态可保存在当前可视化的宿主状态中，不保存图像或个人数据。文件在本线程可视化目录 `star-fox-2d-interactive.html`，不作为应用路由文件或课包资产。

使用 jsdom 与本机 Canvas 实际执行该内容：脚本语法通过，改变开口滑杆后输出值为 80% 且真实绘制像素改变，眨眼按钮将左右闭合设为 1。此验证是 DOM/绘制运行检查，不是浏览器录屏或真人捕捉验收。
