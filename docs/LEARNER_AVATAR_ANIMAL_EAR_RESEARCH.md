# 动物耳部运动：重审当前随动

> 后续实施已完成：见[耳廓主动转向修正](LEARNER_AVATAR_EAR_ORIENTATION.md)。本文保留调研当时的事实与证据边界，开头的“尚未修改”是历史状态。

日期：2026-11-03。用户指出上一轮耳朵动作不像动物，要求先了解狐狸、浣熊、兔子、猫。本轮完成资料核查与实现审视，**尚未修改渲染代码或宣称新耳动已完成**。

## 当前实现的问题

`painted-secondary-motion.ts` 将同一套正弦脉冲和阻尼弹簧用于四角色；角色之间主要区别是耳根/耳尖位置、增益和相位。每个耳廓像素因位置不同应用不同的画面内旋转角度，形成可见弯折。目标主要是放大耳尖位移和回弹，没有表现耳廓主动转向、保持方向与内外耳面的可见变化。毛发也被同一套时间函数持续驱动。

因此，上一轮“有位移、网格不折叠、脸不变”的检查只证明程序正常，**不能证明运动符合动物行为**。20–30px 不是耳动自然度指标；继续增加幅度或调整弹簧不会解决运动方向错误。

## 查证内容与适用边界

| 动物 | 已支持的事实 | 对角色动画的设计推论 |
|---|---|---|
| 赤狐 | 两耳可独立运动，以定位声音。[RSPCA](https://science.rspca.org.uk/en/web/rspca/adviceandwelfare/wildlife/foxes)；[Wildlife Online](https://www.wildlifeonline.me.uk/animals/article/red-fox-senses)有一耳向前、另一耳向后的照片与作者观察说明 | 应优先表现完整耳廓从耳根调整朝向，一耳先转、短暂保持再归位；不把尖耳当柔软饰物连续左右弯甩 |
| 猫 | 双耳可独立转动，耳位参与交流。[Cats Protection](https://www.cats.org.uk/media/4573/039-thecat_summer20-five-facts.pdf)；[行为指南](https://www.cats.org.uk/help-and-advice/cat-behaviour/cat-body-language)区分前向放松、侧后向/压耳等情境 | 默认用小幅单耳转向/回正；压耳应是有情境的表达，不作为默认呼吸循环 |
| 直立耳兔 | 双耳可独立定位声音。[RSPCA 饲养行为资料，正文第 1 页](https://www.rspca.org.uk/documents/1494935/9042554/Rabbits%2B%282011%29%2B%28PDF%2B559KB%29.pdf/90415d22-9b4b-07c7-fb47-4f214800a307?t=1557664858077) | 长耳首先从根部调整整体朝向，耳尖只保留有限柔性；不将当前长耳做成飘带式波动。该条是动画设计推论，不是本轮测得的角度/速度 |
| 小熊猫 | 当前红棕角色原稿与目录是小熊猫，不是浣熊。圣迭戈动物园资料汇总记录过嗅探时耳后置、特定对抗姿态耳前向等情境。[行为资料](https://ielc.libguides.com/sdzg/factsheets/redpanda/behavior) | 单独建立小熊猫参考，不能套用猫/兔的动作幅度、周期或情绪解释；小幅动作只是后续候选，需要真实运动参照确认 |
| 浣熊 | 本轮检索未取得足够可靠的物种专门耳动曲线/频率资料；没有把其他物种的研究结果算作浣熊结果 | 保持为资料缺口；不擅自改现有小熊猫身份，也不编造“浣熊每几秒抖耳”的参数 |

另一个重要的一手实验：[Tollin 等，2009，The Vestibulo-Auricular Reflex](https://pmc.ncbi.nlm.nih.gov/articles/PMC2666401/)。研究猫朝目标转头时的耳部运动，观察到耳廓能通过相对于头部的反向运动，在一定阶段维持对目标的朝向。论文也指出这种补偿有方向/情境差异。它支持“耳朵是主动定向系统，不能只当被动弹簧”，**不能外推成所有动物、所有转头时都必须等量反向转耳**。

本轮阅读了机构文字、图示/照片说明与研究论文；没有逐帧分析真人拍摄的四物种视频，没有测量真实耳动角度、速度或事件频率。此前 7.7s/10.3s、1.35s/1.65s 都是人工动画参数，不是生物统计。

## 下一版的实现依据

1. 将**主动耳廓定向**与**发梢被动随动**分开。耳朵采用“转向 → 短暂保持 → 归位”，保留大量静止时间；不使用每种动物同一条连续摆动/回弹曲线。
2. 同时表现耳廓朝向与俯仰：整体耳形、内耳露出面积、前后缘遮挡关系变化，耳根接合稳定；局部毛尖才做小量柔性。真正难点是现有正面画稿没有背耳/侧耳内容。
3. 保持 2D 画风。小角度可以尝试有结构的局部网格与内耳遮罩；明显侧转需要少量对齐的侧/背耳素材或 2.5D 局部结构，不能仅靠拉伸正面纹理冒充。
4. 先在星狐上对照“正向、单耳转向、保持、回正、头动中耳向稳定”验证轮廓与节奏，再按各物种参考扩展。不能只以像素变化更大作为通过条件。
5. 头发只在转头/停下后保留克制的惯性；静止时减少无风自摆。角色长发属于拟人化美术，不能借动物行为资料声称其持续飘动是生物真实性。

本文件是后续耳动重做的依据，优先于上一轮“自然小动作已完成”的生物自然度暗示。研究阶段的可运行版本与素材均保留；后续实现与提交状态以主交接文档为准，未合并/部署。
