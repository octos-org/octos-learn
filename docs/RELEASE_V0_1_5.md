# Octos Learn v0.1.5

建立笔迹选区后，工具栏原先等待图片生成、上传和模型内容识别完成，才显示“解释这部分”“检查并建议”等快捷操作。本版根据已有工具注册表立即显示接受未知内容类型的通用操作；后台识别可靠地返回数学内容后，再补充“生成函数图像”。识别失败、低置信度或类型未知时，通用操作仍可使用。

切换选区时同步清除旧识别结果及内容类型，提前点击使用当前选区快照与图片，不带入上一个公式。这是适用于所有选区的显示与状态修复，不修改模型、提示词或技能，不增加模型往返，也不宣称缩短图片上传或模型识别本身的耗时。

## Android 与交付

Android 包名 `cc.pitun.learn`，versionName `0.1.5`，versionCode `36`，最低 Android 8.0。正式 APK 从合并后的干净 `main` 源码构建，沿用 v0.1.4 签名，以保留数据的覆盖方式更新。九门内嵌课程快照和上游依赖保持不变，确切版本见 `learning-stack-bom.json`。

正式 release 附带 APK、SHA-256 和公开构建验证 JSON。发布后重新从 GitHub release 下载 APK，核对与构建产物一致，再复制到 U 盘根目录并安装到本地皓丽大屏。设备状态和本地交付记录单独保存在本地，不包含在公开验证附件中。本轮交付不包含公网服务器部署。
