# 数学质量实施状态

更新日期：2026-09-06。状态：本地实现与验证完成，尚未合并或部署。

## 实施结果

- OLL `codex/math-quality` 已包含并推送 `d6a65e6`、`f81b494`、`783617e`、`c87fe9f`。前端与 Learning Coach 都精确锁定 `c87fe9f`。
- 函数图由程序选择教学视窗，只有原点位于范围内时才绘制真实坐标轴；零刻度可见，横纵单位等比例显示。用户可缩放、平移、重置、打开大图、读点并控制图例；卡片按内容测高，大图位于视口中心，并在课程销毁时同步关闭。
- 圆面积使用带曲边的真实扇形重排，明确有限分割只能逼近长方形；圆面积请求不能再由三角形拼矩形替代。
- 斜率课程支持两个独立滑块、两个采样点、割线、`Δx`、`Δy` 和斜率反馈。固定函数上的采样点移动不会错误宣称函数斜率改变，点重合时显示斜率不可计算。
- 简短主题、问题式、困惑式和带上下文输入共纳入 67 个自然输入案例；空白输入界面提供三个仅预填、不自动提交的主题建议。信息不足的提问会保留问题卡片，显示补充信息提示并通过 TTS 朗读。
- 教学能力和禁用关系保留在程序侧 contract，没有把完整 registry 写入每次模型 prompt。可确定修复由本地编译器完成，普通成功路径没有新增模型调用。

## 速度守门结果

静态预算比较冻结的旧生成器与当前候选，覆盖 67 个请求。`system + prompt + schema` 每个请求至少减少 215 bytes，没有 prompt 增长案例；明确不支持的四维旋转请求降为本地零模型输入。

使用同一台机器和 `gemini-3.6-flash` 对三个短输入各做 5 组交错基线/候选测试，共 15 对：

| 指标 | 冻结基线 | 当前候选 | 结果 |
| --- | ---: | ---: | --- |
| 成功 | 15/15 | 15/15 | 相同 |
| bootstrap 输入 token p50 | 1529 | 1505 | -24 |
| 首个可播放片段 p50 | 6396 ms | 6466 ms | +70 ms（约 1.1%，配对结果 7/15 更快） |
| 整课 p50 | 6950 ms | 6471 ms | -479 ms（约 6.9%，配对结果 8/15 更快） |

候选有一次旧 `reusable_item` 触发局部修复；之后已在程序侧清理该冲突，并用连续三次二次函数生成确认 0 次修复。网络与模型本身的抖动无法作绝对时延保证，但当前证据确认：模型输入更短、正常路径调用拓扑不增加、整体生成没有可重复的速度回退。

原始对照数据见 `math-quality-results/paired-v5-summary.json`，静态预算见 `math-quality-results/prompt-budget.json`。

## 自然输入评测
