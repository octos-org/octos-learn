# Octos Learn v0.1.3

This release includes Learn PRs [#51](https://github.com/octos-org/octos-learn/pull/51), [#52](https://github.com/octos-org/octos-learn/pull/52), [#53](https://github.com/octos-org/octos-learn/pull/53), and [#54](https://github.com/octos-org/octos-learn/pull/54), OLL [#23](https://github.com/alan0x/octos-lesson-language/pull/23), and Learning Coach [#24](https://github.com/alan0x/learning-coach/pull/24).

- Slider dragging reuses plot dimensions, avoids repeated whole-board geometry scans, and saves the latest checkpoint approximately every 400 ms during sustained dragging. Pausing saves the final value; committing saves immediately. Large Android whiteboards can still stutter; the user accepted the measured performance for this release.
- CoursePack and generated-course playback progress survive reload and coexist on one board. Completed practice stays with its course, and queued practice identifies the course it is waiting for.
- Settings displays the app version and Git revision.
- Learning Coach aligns geometry rearrangement narration with construction facts and animation state, including inherited numerical parameters and labels, without adding model review rounds.

Android uses package `cc.pitun.learn`, versionName `0.1.3`, versionCode `34`, minimum Android 8.0, and the existing signing certificate for data-preserving updates. The nine embedded courses retain snapshot `curated-e2e-closeout-2026-09-30`. The frontend runtime is pinned to merged OLL `15ee0095f317fe868c0f0af4bfae55abd8e70b55`; Learning Coach is recorded at merged `ed211feeeae7bbac98b7db6062f2ca31c4a175ba`. Other component revisions are recorded in `learning-stack-bom.json`.

The signed APK and public web build must come from the clean, merged release-preparation revision. The release verification attachment records the exact source revision, APK digest and certificate, embedded course digests, CI results, and public deployment checks. Only the public frontend needs replacing if the VPS's installed Learning Coach already matches the merged generator tree. Preserve the current backend, hosted TTS policy, configuration, and user data; take encrypted backups before deployment.

Validation includes the merged changes' unit and browser checks, the Android slider measurements and persistence/layout checks in the [final performance report](course-runtime-quality/webview-slider-performance-2026-10-10/REPORT.md), generator contract and recorded-response checks, and final release artifact/public smoke checks. Automated fixtures do not establish real microphone, camera, ASR, or audiovisual acceptance.
