- [ ] S3-04 在 Learning Coach 的普通、摄像头和选区课程入口统一接收并使用老师设定，让相关生成阶段真正受其影响；不另加一轮模型来改写风格。
- [ ] S3-05 根据已知课堂事件实现开始、等待、被打断和任务完成等固定反应，控制重复频率；台词不得超出实际证据。
- [ ] S3-06 接通音色和可用动作，检查网页与 Android，覆盖音频预取/缓存和切换老师后的声音归属；使用学生本人的语音凭据。
- [ ] S3-07 确定预制课原录音与老师音色怎样相处，明确显示原声、制作多音色版或另行合成的取舍，不假定换头像能改变包内旁白。
- [ ] S3-08 先在没有不同学生记忆的条件下验证基础性格能否辨认、数学和互动是否正确、学生当前要求是否被尊重；验证首段速度。

交付应是可选择、可体验的老师，以及设定卡、情境范例和各端验收结果。

## 阶段四：老师记得学生，并在相处中成长

- [ ] S4-01 一起确定共享规则：学习进展、教学偏好、共同经历分别给哪些老师使用；保留真实参与者，不让另一位老师冒称亲历。
- [ ] S4-02 确定明确要求何时生效，怎样区分“今天这样讲”和“以后这样讲”，冲突时怎样处理；未经确定不锁死所有老师的行为。
- [ ] S4-03 核对并改正 Learning Coach 仓库和已安装技能里独立处理跨课记忆的旧指令，保留当堂状态，长期记忆处理统一交给 Octos。
- [ ] S4-04 打通课程使用真实学习事实及 Octos 相关记忆的路径，取与当前问题相关的部分，注明来源和截至时间；记忆暂不可用时仍能开始课程，不编造回忆。
- [ ] S4-05 把发生过的师生交互及明确反馈交给 Octos，验证后续课程能够使用有效偏好和共同经历；每个学生分别成长。
- [ ] S4-06 提供查看、请求记住、纠正和遗忘的界面，实际调用 Octos；将“已接收”与“已生效”说清，学习记录删除与语义记忆遗忘分别解释。
- [ ] S4-07 核对现有 Octos 能否表达和执行已确定的规则；只有证实必要的通用缺口才改上游。旧后台结果偶尔写回等窄场景按用户已允许的范围处理，不扩成必做的大工程。
- [ ] S4-08 做跨多次上课、换老师、换账号、没有反馈、改偏好和遗忘的连续验收；确保没有依据时不推断喜欢程度或掌握情况，并验证速度和后台费用。

交付应让学生真正感到“这位老师记得我们以前怎么学”，而不只是显示一段固定欢迎语。

## 阶段五：知识地图与有趣的成就

- [ ] S5-01 用固定版本的 os-taxonomy 构建首批小范围地图，核对学科覆盖、来源和版本升级规则，不把上游目录误当成学生学习状态。
- [ ] S5-02 明确各状态表示什么：暂无记录、已探索、正在练习、已有规定的理解证据；拖到结尾、看完或滑块成功均不自动代表整章掌握。
- [ ] S5-03 从同一份可靠学习事实计算地图进展，支持查看依据；课只播放了一部分时，只体现实际接触的范围。
- [ ] S5-04 制定少量成就的触发、计数和重复颁发规则，先由程序确认条件，再让老师按自己的风格表达。
- [ ] S5-05 制作幽默、可适度调侃的徽章与颁发语，尊重学生，不把反复学习描述成笨或失败；具体文案待审。
- [ ] S5-06 让老师读取与地图和成就一致的状态，避免说“已掌握”而地图只有“已探索”；换老师、刷新、断网重连后不重复发奖。
- [ ] S5-07 验证 taxonomy、课程和对应表升级时旧学习依据仍保留，新增节点不会凭空继承已完成状态。

## 阶段六：主动学习建议、报告与试卷

- [ ] S6-01 确定先做哪项、给谁用、怎样启用；主动建议、周报/月报、月考试卷逐项交付，不把列入 TODO 当成自动开启。
- [ ] S6-02 根据真实进展和适当的复习依据提出学习建议；可以拒绝或跳过，没有记录不等于学生不会，久未使用不等于已经忘记。
- [ ] S6-03 确定报告周期、时区、内容、送达和关闭方式，区分发生过的学习与有证据的进步。
- [ ] S6-04 设计试卷范围、难度、题目正确性、判分与讲评；知识点不确定时不拿猜测出卷，考试结果作为新事实保存。
- [ ] S6-05 设计后台执行、失败补做、通知去重及费用限制，复用适用的 Octos 通用能力；不在 Learning Coach 另建语义记忆流程。
- [ ] S6-06 分别验收建议、报告或试卷的实际体验、准确性、费用及对正在上课的影响。

## 后续持续改进

- [ ] C-01 增加更有教学意义的作答与错误依据，评估是否理解得更好、能否更独立完成，而非只看播放时长。
- [ ] C-02 在 Octos 中验证较弱反馈形成的待验证理解怎样更新或撤回，避免仅凭沉默、暂停、回放就固定学生偏好。
- [ ] C-03 根据实际体验扩充老师、素材和学科覆盖，保留稳定性格和每位学生独立成长的边界。
- [ ] C-04 持续验证数学质量、首段速度、后台费用，以及资料删除、版本升级和跨设备恢复等已披露限制。
