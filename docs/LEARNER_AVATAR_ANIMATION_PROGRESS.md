## 已实现

1. 独立、按需加载的试验室路由；没有在普通 AI 课程路径增加模型往返。
2. 自制三维工程测试角色，连续嘴型开合、左右眼、眉毛、头部与视线控制；目标 30/60 FPS 可选，停止后停止连续渲染。
3. MediaPipe 0.10.32 的 CPU 识别在独立经典 Worker 中运行；模型与 WASM 本机托管。
4. 摄像头只请求视频；只有用户点击后才请求权限，不采集音频、不上传画面。
5. 生命周期覆盖退出路由、隐藏页面、停止、权限迟到、位图迟到、加载失败与加载超时；对应测试验证资源释放。
6. 统一命名的 52 通道兼容清单；按来源保留实际支持的通道，不以数组序号硬套映射。
7. 自然表情校准、不同部位的平滑、失跟返回待机。
8. 不使用摄像头的演示动作，以及真实本机模型对空白画面的自检；二者在界面明确区分。
9. 最长 60 秒的表情片段录制、暂停/回放/定位、JSON 导入/导出。只包含角色参数，当前片段留在内存；用户可主动导出或保存到本机片段库。
10. 实际显示帧率、识别与取帧到结果的 p95、绘制提交耗时，以及观察报告导出。界面明确这些不是完整动作延迟或 GPU 总耗时。
11. 复用现有 `TeachBoard` 与 Ink Runtime 的试写区；试写内容与本机 profile 对应，不加入课程草稿。
12. 已选星狐三张概念图保存到 `public/teach-avatars/star-fox/`，试验室展示其为正式模型的参考。
13. iOS 原生 ARKit 捕捉伴侣的 Xcode 工程源码；捕捉、校准、最多 60 秒参数导出、后台停止。当前用文件导入打通数据格式，尚无实时网络配对。
14. 本机表情片段库：使用 IndexedDB，复合账号/片段键隔离；主动命名保存、重开、改名、移入回收站与恢复。元数据与动作原子写入，列表不加载全部动作帧；重名 ID 拒绝覆盖。存储失败明确提示，仍可导出当前片段。清除浏览器数据会丢失库，需自行导出备份；无云同步。
15. 六段固定 4 秒、121 帧的合成排练：张嘴与闭嘴、左右眨眼、微笑着讲述、圆唇与放松、转头与点头、遮挡与恢复。均标记 `demo`，无需摄像头，可播放、定位、导出并保存，不能作为真人捕捉质量证据。
16. 配音与嘴型本机排练：导入已生成的短配音，读取真实媒体时间以支持暂停/跳转/变速；离线 RMS 包络基础开合、音频哈希绑定的外部发音轨导入/导出。详见[配音与嘴型说明](LEARNER_AVATAR_AUDIO_SYNC.md)。
17. 正式模型接入契约、按名称绑定运行模块、GLB 元数据检查命令与[星狐模型交付规范](LEARNER_AVATAR_MODEL_SPEC.md)。要求精确模型哈希、52 通道覆盖/缺失声明、基础嘴眼通道和唯一节点/目标；现由小样 GLB 验证真实加载与绑定，尚无验收后的正式资产。
18. 录课作品预览的“准备分享”可选保存基础嘴型：复用每卡唯一一次 TTS 的最终音频，生成自包含音频/嘴型 v2 课包；默认仍为 v1。试验室可导入 v2 并逐卡读取原始嘴型试听。格式校验、取消/迟到任务和不可用音色处理已加入；没有把工程测试模型当正式角色打包。
19. 作品预览和下载课包播放器叠加按需加载的工程角色，共用真实配音时钟；下载包完整播放白板/配音且严格禁止缺失音频时回退调用 TTS。嵌入白板布局、头像开关、图形降级与跨卡/跨包时钟隔离已覆盖。
20. [星狐三维小样 v0.1](LEARNER_AVATAR_STAR_FOX_SAMPLE.md)：原创参数化建模源、可重建的 1.62 MB GLB、21 通道/68 网格形变目标，实际模型加载并替换共享舞台中的早期角色；新增无摄像头定格检查。其余 31 通道明确不支持。
