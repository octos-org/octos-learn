| 实际播放与练习事实 | 直接采集播放、作答和提示；跳转/恢复不冒充学完，回放不增加一遍；旧实机证据只覆盖对应旧版本 |
| 知识点问题和讲解分别判断 | Octos 调用本人模型查固定目录，分别返回原问题和片段的依据；产品校验编号/原文/内容指纹并计算次数 |
| 真实模型有限样例 | 九份固定材料程序和独立 agent 内容核查通过；第二题为真实原回答离线复验，原停止记录保留，详见 TOPIC_FINAL_SEVEN_RESULT.md |
| 已交付后生成失败 | 新增 request_failed，按执行编号去重、绑定问题，失败不删除部分交付。多任务先失败、文件查询未返回及执行编号重标均有回归；见 REQUEST_FAILURE_EVIDENCE.json |
| 默认关闭及课堂让出 | 空闲应用才执行、原任务可恢复、每日任务限制；不是后台全天运行，也不是普通使用的美元硬上限 |

失败记录只保留执行编号、失败/取消和固定原因，不保存错误正文，不作为老师回应或新分析材料。一次请求可有多个执行，其中一个失败不表示整题没有有用内容。旧服务同步返回 jobs=[] 且没有明确结果时，不猜测补记缺少产物。

最新修复免费验证：前端 136 文件 / 1,255 项，服务 40 项，控制 12 项，类型/public 构建和定向 lint 通过（零错误、两条既有警告）。独立 agent 对两项发现的修复复核通过。此前 53dfeac 的完整 GitHub CI 已成功；新增修复的 CI 须单独确认，不冒用旧检查。
