# task-v2 练习归属：真实模型质量检查准备

2026-10-22。对应 S2-08c / P2-14 及[调整后的推进顺序](../PERSONALIZED_TEACHERS_DIRECTION.md) C 段第一项。旧九份 v1 样例不含练习，不能代替本检查。

## 为什么要单独做

规则 `separate-question-beat-and-task-units-v2` 让课程里每道练习单独归属知识点，练习作答次数、成功和提示按这个结果计入。免费测试只证明链路和计数正确，不证明真实模型把练习归对。第五阶段的知识地图会直接使用这些计数。

## 用例（[TASK_V2_CASES.json](TASK_V2_CASES.json)，预先写定，期望不发给模型）

4 节课、8 道练习，每道都有预先声明的状态和可接受知识点：

| 课程 | 练习 | 期望 | 检查什么 |
|---|---|---|---|
| 斜率课 | 由两点求斜率 | Linear Function Graphs / Plotting Linear Graphs | 正常归属 |
| 斜率课 | 调截距使直线过 (0,-2) | 同上 | 截距也属一次函数图像 |
| 斜率课 | 三角形第三个角 | 三角形内角和两个节点之一 | **不能照课程标题归到斜率** |
| 内角和课 | 直角三角形求第三角 | 三角形内角和 | 正常归属 |

| 一次函数练习 | “把 k 调到正确的值” | unknown | 题目本身没有问题，不能从旁白补 |

不匹配不会中止执行（这是要测量的结果）；结果仍需人工或独立 agent 复核引用。

## 执行方式

- 使用隔离的真实 Octos 413b4b68（`--execute-isolated`），唯一模型路由是本次预算网关；Key 来自用户自己创建的 `~/.config/octos-trial/gemini.key`，不读取、不改动用户自己的 Octos。执行结束删除隔离 Octos 数据和配置（含 Key），日志含 Key 时删除日志。
- 控制：4 项、最多 16 次请求、每项最多 6 次；每次请求按 100 万输入 + 65536 输出 token 预留 1.10 美元，**上限 17.60 美元，不是账单**。以往同类分析每次请求实际约 0.01–0.03 美元，预计总计不到 0.5 美元。
- 计划 [TASK_V2_TRIAL.json](TASK_V2_TRIAL.json) 状态 prepared，固定代码、用例、目录和 Octos 二进制指纹；需用户批准预算后改为 approved 并在执行当天复核价格。
