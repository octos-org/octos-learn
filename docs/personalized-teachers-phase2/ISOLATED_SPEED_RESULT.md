# 隔离环境首段画面速度对照（方案 B，2026-10-26）

用户 2026-10-25 授权付费速度测试，2026-10-26 选择方案 B：不用本人账号，在隔离的 Octos 里用测试 Key，只测首段画面，不测语音。对应总清单 N-04（可选的真实供应商对照）。

## 测了什么

- **两个前端**：基线 main `4973499`（加入学习记录之前），候选 main `1615575`（学习记录、三位老师、星图、成就、学院大厅等全部合并后）。两份生产构建交替运行，每节课用新的浏览器上下文和新白板。
- **后端**：同一个隔离 Octos（main `5d9e70b4`）和 Learning Coach main `3456f3d`，gemini-3.8-flash，所有模型请求经预算网关。没有配置语音；学习记录、BYOK 和课程目录接口返回 503，不写入任何记录。
- **指标**：从提交问题到本节课第一个课程画面可见、播放控件可用（同一探针，`visual_ms`）。不包含语音，不等于原执行单的“首段可播放”。
- **差异来源**：候选版本在请求里多带老师设定（新账号默认阿澜），后台多了学习记录代码；学生背景为空（新账号没有记录和记忆）。
- **执行器**：`scripts/benchmark-playable-isolated.mjs`（新增）。执行单 `ISOLATED_SPEED_*PLAN.json`，原始结果 `ISOLATED_SPEED_RESULT_*.json`。

- 没有配对的样本：第 2 对候选 12.0 s（它的基线没有生成课程）。
- **三角形题两次被模型拒绝生成**（第 2、5 对的基线）：模型回答“当前图形组件不支持可自由拖动顶点的三角形”，没有课程画面。这是课程生成能力的问题，与前端版本无关，记为不可比；同一题第 2 对的候选版本生成成功，说明是随机出现的。按执行规则，失败即停止，用新账本续跑剩余的对，共三轮。
- 费用：23 次模型请求全部通过预算网关；执行器没有记录每次用量，按以往每节课约 0.01–0.02 美元估计合计约 0.3 美元，预留上限合计 3.45 美元（不是账单）。输出文件扫描 Key 片段 0。

## 结论

- **未发现回退**：候选的中位数不高于基线，满足“首段 p50 不高于基线”的门槛。
- **但差异几乎全部来自模型**：同一题同一版本，从 15 秒到 48 秒都出现过；一节课用 1、2 还是 3 次模型请求，时间可以差 20 秒以上。前端多出的工作（此前免费对照测得几毫秒）淹没在模型波动里。样本只有 5 对，这个测试能说明“没有明显变慢”，不能精确到秒。
- **没有覆盖**：语音、本人账号的真实学生背景和记忆（真实使用时请求里会多带学生背景）、电视设备。
